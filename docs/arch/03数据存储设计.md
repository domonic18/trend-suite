## 1. 技术栈

| 项 | 选择 | 说明 |
|---|---|---|
| 主库 | PostgreSQL 16 | 事务 + JSONB + 向量扩展 |
| 向量 | pgvector | 与主库同源，避免双写一致性 |
| 迁移 | `apps/cloud/db/migrations/NNNN_description.sql` | SQL-first、幂等可回放；命名递增不重排 |
| 分片 | 起步不分区 | 数据量级（69 集课程）单库足够；达阈值再按 `course_id` 分区 |
| 大文件 | 对象存储（MediaStore 抽象），DB 只存路径与元数据 | 见 06 文档 |

## 2. 领域模型

### 2.1 账号与授权

| 表 | 关键列 | 不变量 |
|---|---|---|
| `users` | id / username / password_hash(scrypt) / role / status | role ∈ {student, producer, operator, admin}；密码只存哈希 |
| `devices` | id / user_id / device_label / last_seen / status | 一个账号可多设备；解绑置 revoked |
| `sessions` | id / user_id / token_hash / expires_at / revoked_at | token 只存哈希；轮换写新行 |

### 2.2 内容与生产

| 表 | 关键列 | 不变量 |
|---|---|---|
| `media_assets` | id / course_id / source_path / sha256 / duration_s / status / hls_path / video_ok / audio_ok | 状态机 `awaiting_upload → uploaded → processing → ready`（失败 `failed`）；必须有视频流且有音频流 |
| `transcript_segments` | id / asset_id / start_ms / end_ms / text / speaker | 时间戳单调不重叠；正文只存 DB，不进日志 |
| `source_units` | id / course_id / asset_id / start_ms / end_ms / text / visual_desc / concept_refs | `(asset_id, start_ms)` 唯一（重跑按缺失 chunk 补齐）；事实回溯的最小证据单元 |
| `concepts` | id / course_id / name / aliases[] / definition / status | 同课程内名称唯一（重复名拒绝）；别名参与术语校验 |
| `concept_edges` | from_id / to_id / kind(prerequisite\|related) | `prerequisite` 子图无环 |
| `sections` | id / course_id / title / order / dsl_version / article_md / status | article 事实段必须带 `[[unit:]]` 锚；发布前状态 `draft→published` |
| `figures` | id / section_id / kind(keyframe\|diagram) / caption / asset_id / sec / spec | 每节 `keyframe` ≤6、`diagram` ≤2；`figure:` 引用必须可解析 |
| `widget_specs` | id / section_id / type / spec_version / spec / assertions / validation | 断言必须有证明记录，否则拒绝入库；`bar-replay-decision` 按 `(sectionId, code)` 唯一 |
| `section_case_stocks` | section_id / code / name / exchange / period / window / events[] | `period ∈ {1d,1w}`；事件 `date` 落窗口内且可回溯 unit |
| `segments` | id / course_id / asset_id / from_sec / to_sec / title / text / embedding | 片段窗 ≤120s；embedding 可空（未索引只词法召回） |
| `production_tasks` | course_id / section_id / step / status / attempts / heartbeat_at / checkpoint | `(course_id, section_id, step)` 幂等 upsert |
| `approvals` | course_id / fingerprint / approver / verdict | 指纹覆盖一切会被发布的内容（07 文档 §5） |
| `case_stock_quotes` | code / period / trade_date / o / h / l | v（手）/ amount(null) | 唯一键 `(code, period, trade_date)`；**周期原生**存储（日/周分别存） |

### 2.3 消费与计费

| 表 | 关键列 | 不变量 |
|---|---|---|
| `progress` | user_id / course_id / section_id / seconds / completed | 幂等：时长取最大值；完成不回退 |
| `playback_sessions` | id / user_id / section_id / asset_id / from_sec / to_sec / expires_at / watermark | 窗口须完整落在该节已发布 clip 窗内；短时效 |
| `quota_ledger` | id / user_id / delta / reason / ref_id / idempotency_key / created_at | **余额 = SUM(delta)**；扣减必须带幂等键防重放；明细不含问题原文 |
| `recharge_orders` | id / user_id / amount / channel / status / paid_at | 支付成功即时到账；重复回调不重复加额 |

### 2.4 模型与用量

| 表 | 关键列 | 不变量 |
|---|---|---|
| `ai_models` | id / purpose / provider / model / api_key_enc / status / cooldown_until | 密钥 AES-GCM 加密，仅管理端维护；明文不出管理端 |
| `ai_task_bindings` | task / primary_model_id / backup_model_id | 任务级主备；主备冷却健康检查 |
| `ai_runs` | id / source / task_key / model / provider / tokens / latency_ms / summary | 与云端自身任务同一账本；`source ∈ {cloud, producer, student_qa}` |
| `ai_usage_events` | run_id / kind(tokens\|images\|asr) / amount | 预算 80% 预警 / 100% 硬停新增调用 |

## 3. 索引与检索设计

| 用途 | 方案 |
|---|---|
| 混合检索 | 词法（tsvector / trigram）+ 向量（pgvector 余弦）；候选合并后 rerank |
| 引用可回溯 | 检索结果只允许引用 `segments` / `source_units`（已发布内容），生成端不得自造时间点 |
| 目录树 | `sections.order` + `courses.order` 稳定排序；`catalog` 只读 published |
| 关键帧轨道 | `media_assets` + 帧文件清单；按 `[from,to]` 时间窗查询 |
| 行情 | `(code, period, trade_date)` 唯一 + `(code, period)` 前缀扫描；周线原生缓存 |
| 额度 | `quota_ledger(user_id, created_at desc)`；幂等键唯一索引 |

### 3.1 在线检索管线（实现级）

检索是问答链路的**唯一内容来源**，其召回质量直接决定回答质量。实现口径（继承 trend-studio 已验证实现）：

```
POST /v1/kb/search（Bearer + x-device-id）
  → 鉴权 / 限流 / 入参校验
  → query embedding
  → 向量召回（halfvec 余弦，topN = max(topK × 4, 20)）
  → 词法召回（pg_trgm 相似度 + 关键词命中，topN）
  → RRF 融合（k 可调，默认 60）→ 同片段去重
  → 阈值判断 → 裁剪 → segments[] / relatedKnowledgePoints[]
```

| 环节 | 规则 |
|---|---|
| 向量召回 | `halfvec` 余弦距离，取 `topN = max(topK × 4, 20)` |
| 词法召回 | `pg_trgm` 相似度 + 关键词命中，取 `topN` |
| 融合 | RRF（`k` 默认 60），同片段去重 |
| 候选阈值 | `SEARCH_MIN_SIMILARITY`（默认 0.05）只负责捞候选 |
| 置信阈值 | `SEARCH_MIN_CONFIDENCE`（默认 0.15）过滤单个 trigram 级别的偶然命中（短 query 与标题补位字符重合）；过滤后为空即按**未覆盖**处理 |
| 回退 | 未覆盖时填充 `relatedKnowledgePoints`（同一置信阈值、≤5、**仅 id/标题，不带起止秒与正文**） |
| 裁剪 | 输出 Top-K；`score` 归一化到 `[0,1]`；字段与长度按契约校验；整体超出 **512KiB 报错而非截断** |
| 索引触发 | 发布事务内同步 embedding；未配置 embedding provider 时允许发布（`indexed=false`，仅词法召回）；**生成内容绝不自动进入检索** |

**质量门槛**：自建评估集 ≥100 条真实学员问题，Top-5 命中率 ≥90%；每次索引或排序变更必须跑回归。

### 3.2 检索入参边界

| 字段 | 规则 | 越界 |
|---|---|---|
| `query` | 去首尾空白后 1–500 字符 | `400` |
| `topK` | 整数 1–20，默认 5 | `400` |
| `courseId` | 可选，≤64，`[A-Za-z0-9._-]` | `400` |
| `segmentId` | `^seg-[A-Za-z0-9._-]+$`，≤80 | `400` / 不存在 `404` |

## 4. 事务与一致性

| 场景 | 边界 |
|---|---|
| 产物写入（节教材/图示/课件） | 单事务：全部落库或全部回滚；**绝不部分落库** |
| 发布 | 单事务翻状态（章节/图示/课件/片段/案例股）+ 内容指纹比对；失败不翻状态 |
| 额度扣减 | 单事务写 ledger（幂等键唯一）+ 读余额；重复请求返回同一结果 |
| 行情回填 | 幂等 upsert（唯一键覆盖），重跑行数不变 |
| 进度上报 | 单事务取 max(seconds)，完成标记只置不改 |

## 5. 迁移规则

1. 文件名 `NNNN_description.sql`，序号只增不重排；一次迁移一个关注点。
2. **幂等可回放**：`IF NOT EXISTS` / `DO $$ ... $$` 保护；回放两次结果一致。
3. 破坏性变更走「新列 → 双写 → 回填 → 切读 → 删旧列」多步，不在单次迁移里丢数据。
4. 迁移注释写明**不变量**与**回滚方式**；涉及检索口径的迁移必须同步 `packages/contracts` 版本。
5. 数据库迁移后同步测试夹具与行为基线数字。
