# 02 云端服务架构

版本：v1.0（2026-11-12）
关联：[01 整体架构设计](01整体架构设计.md) · [03 数据存储设计](03数据存储设计.md) · [05 内容生产链路实现方案](05内容生产链路实现方案.md)

> 本文回答「云端由哪些模块组成、请求怎么进、任务怎么跑、怎么部署与运维」。
> 继承说明：模块划分、worker 状态机、部署与发布流程继承 trend-studio `apps/cloud` 已验证实现；按 ADR-02 调整的是**生产执行位置**（本机插件 → 云端 worker）。

---

## 1. 形态与进程

单服务多域（起步期同进程同库，模块边界预留拆分点）：

```
Fastify 主进程
├── HTTP 层：路由 + schema 校验（zod，来自 @trend-suite/contracts）+ 错误映射
├── 领域层：accounts / catalog / content / production / pipeline / playback / billing / ai / ops
└── 静态与前端产物：/admin（管理台 SPA）、/（门户预渲染 + 注册/登录/设备授权/个人中心）

Worker 池（同一镜像，独立进程/副本，由 APP_ROLE 区分）
├── pipeline-worker：上传后处理（转码 / ASR / 关键帧 / 帧轨道）
├── production-worker：Agent 生产编排（九步引擎）
└── quotes-worker：行情缓存回填与日更
```

- 路由前缀：`/v1/admin/*`（教师/运营/管理）、`/v1/catalog/*`（学员只读内容）、`/v1/auth/*`、`/v1/ops/*`（运营）、`/v1/billing/*`（额度与充值）、`/v1/ai/*`（模型配置与用量）。
- 前端产物由同服务提供，避免跨域与第二套鉴权。
- 伸缩维度：api 按请求量；pipeline-worker CPU/IO 密集（ffmpeg 子进程限并发）；production-worker 按任务并发（单课并行度另有上限，见 05 文档）。

## 2. 领域模块与职责

| 模块 | 职责 | 关键表 | 关键接口族 |
|---|---|---|---|
| `accounts` | 账号、角色、设备码授权、令牌轮换、会话 | users / devices / sessions | `/v1/auth/*` |
| `catalog` | 已发布内容的只读视图：课程树、节详情、目录、进度写入 | courses / sections / progress | `/v1/catalog/*` |
| `content` | 课程内容的权威写面：素材、source units、概念、节教材、图示、课件 spec、案例股 | media_assets / source_units / concepts / sections / figures / widget_specs | `/v1/admin/content/*` |
| `production` | 生产任务状态机、九步引擎、三层校验、回灌与待办、门禁判定、签批与发布 | production_tasks / approvals | `/v1/admin/content/production-*` |
| `pipeline` | 上传落库、转码、ASR、关键帧、帧轨道、HLS 发布 | media_assets / pipeline_jobs / transcript_segments | `/v1/admin/content/media-assets/*` |
| `playback` | 签名播放会话（窗校验、水印、Range） | playback_sessions | `/v1/catalog/sections/*/playback` |
| `billing` | 额度账本、扣减、充值、明细 | quota_ledger / recharge_orders | `/v1/billing/*` |
| `ai` | 模型条目（密钥加密）、任务级主备、用量账本、预算 | ai_models / ai_runs / ai_usage_events | `/v1/ai/*` |
| `ops` | 运营控制台数据：就绪度、发布、账号管理 | 复用上表 | `/v1/ops/*` |

**写面唯一**：所有内容写入只发生在 `content` / `production` / `billing` / `ai` 四个写模块；`catalog` 只读已发布态。学员端永远不直写内容表。

## 3. 鉴权与会话

| 主体 | 凭证 | 约束 |
|---|---|---|
| 教师（producer） | Web 会话，token 仅存 `sessionStorage` | 不落 Cookie；无凭据托管面 |
| 运营/管理员 | Web 会话 | 签批/发布/账号/模型配置仅 operator/admin |
| 学员（student） | 设备令牌（Bearer + device id） | 设备不匹配 `403`；令牌自动轮换，只存本机凭据库 |
| 服务间 | 内部签名凭据（直传、播放签名） | HMAC 绑定素材/字节数/摘要/有效期 |

- 分权：producer 只能写 draft；生产端点接受 producer/operator/admin，**发布与审批只接受 operator/admin**。
- 云端文本一律按不可信数据处理（防提示注入）；生成内容出口前过滤。

## 4. 任务编排（DB 队列 + worker）

```
queued ──claim──> running ──success──> succeeded
   │                  ├──retryable failure──> queued（退避 15s/60s/300s + 抖动）
   │                  ├──terminal failure───> failed
   └──cancel──> canceled          └──cancel_requested──> canceled
```

- 认领：`SELECT ... FOR UPDATE SKIP LOCKED` 认领到期任务，认领即 `attempts+1`、写 `locked_*` 与心跳。
- 心跳：默认 10s；启动时与每 30s 回收 `heartbeat_at < now()-120s` 的 running 任务（回 queued 或 failed）。
- 重试：仅网络/上游 429/5xx/ffmpeg 超时等可重试错误；参数或媒体非法为终态失败。`error_code` ≤64 字符，客户端只见稳定码与静态文案。
- 取消：queued 立即 canceled；running 置 `cancel_requested`，worker 在阶段边界检查并中止（ffmpeg `SIGKILL` 子进程并清理工作区）。
- 幂等：已探测时长复用、已提升 HLS 跳过转码、成功 ASR 块复用、产物一次性写；重复调用返回原映射。
- 生产任务按 `(courseId, sectionId, step)` 幂等 upsert；断点续跑的 checkpoint 落 DB（worker 崩溃恢复不依赖本地状态）。

## 5. 生产执行（ADR-02 后的关键变化）

| 维度 | trend-studio | trend-suite |
|---|---|---|
| 执行位置 | 生产端本机 dsh 插件 | **云端 production worker** |
| 模型 | 教员本机自配 Key | **云端预置模型**（任务级主备，密钥 AES-GCM） |
| 工艺 | SKILL.md 热挂载 | 服务端**版本化工艺配置**（格式待冻结，见 05 文档） |
| 审批 UI | dsh 审批界面 | **工作台审批组件**（门禁①三动作、门禁②评审卡） |
| 产物落库 | 经 admin API | worker 直写内容域（仍走同一校验与门禁） |

不变的核心：四角色 Agent、九步固定顺序、三层校验、回灌 ≤3 次、失败进人工待办、发布硬门禁、内容指纹绑定签批（详见 05 文档）。

## 6. 可观测与用量

- 每个落库产物上报溯源：`(taskKey, model, provider, tokens, skillVersions, targetId, status, latencyMs)` → `ai_runs` / `ai_run_steps` / `ai_usage_events`（与云端自身任务同一账本）。
- 任务键命名空间：`vision.describe`、`content.chunk_summary`、`content.concept_map`、`content.curriculum`、`content.section_draft`、`content.figure_spec`、`content.widget_spec`、`content.rubric_review`、`billing.quota_deduct`。
- **不上报 prompt 与产物正文**，只记数字、模型标识与版本号。

## 7. 部署形态

| 组件 | 形态 | 说明 |
|---|---|---|
| `apps/cloud` | 容器（Dockerfile，`apps/cloud/deploy/`） | API + 管理台/门户静态产物 + worker（同一镜像，`APP_ROLE` 区分） |
| PostgreSQL | 容器（compose 内） | 起步单实例；数据卷挂 `workspace/` |
| 对象存储 | compose 内 minio 或外部 COS | MediaStore 抽象层切换（`MEDIA_STORAGE=local\|cos`） |
| 反代 | caddy（`apps/cloud/deploy/caddy/`） | TLS 终止、静态资源与 API 同域 |
| 学员端 | 不部署到服务端 | 一键安装包（DSH 框架 + 插件）分发 |

compose 三件套：`compose.yml`（生产形态）、`compose-dev.yml`（开发）、`docker-compose-prod.yml`（上线形态），均位于 `apps/cloud/`。

**门户构建与运行口径**（继承 trend-studio 已验证做法）：

- 构建期预渲染公开页，产出 `routes.json` / `sitemap.xml` / `robots.txt`；未知路径落**壳页并标 `noindex`**。
- 预渲染 HTML 响应头 `no-store`（避免内容过期与缓存串味）；公开接口只返回发布清单与聚合计数，不返回正文与内部 ID。
- 门户会话与后台会话**隔离**（`scope=portal`），门户令牌访问后台端点一律拒绝。
- 下载响应强制 `Content-Disposition: attachment`，不暴露可直链的静态路径。

## 8. 发布流水线

唯一入口：`apps/cloud/cicd/deploy.sh`（不得绕过直接改线上容器）。

```
CI（.github/workflows）: check → build → test
   ↓
构建镜像 → 迁移预演（备份 → 跑迁移 → 健康检查）
   ↓
滚动发布（api 先，worker 后；worker 认领完当前任务再退出）
   ↓
冒烟：/healthz、登录、目录读取、问答额度预检、发布就绪度读取
   ↓
失败回滚：镜像回退 + 迁移回退策略见 §10
```

## 9. 配置与密钥

| 项 | 来源 | 说明 |
|---|---|---|
| 端口/DSN/存储 | 环境变量（`.env` 生产注入） | 仓库只留 `.env.example` |
| 模型密钥 | 加密存 `ai_models`，master key 走环境注入 | 唯一长期密钥 |
| 直传/播放签名密钥 | 环境注入 | 短期凭据签发 |
| 设备码/会话 | 数据库 | — |

**任何密钥不入库、不进日志、不进镜像、不进前端产物。**

## 10. 迁移与回滚

| 变更类型 | 回滚方式 |
|---|---|
| 应用代码 | 镜像回退（前一 tag） |
| 加列/加表 | 镜像回退即可（列可留） |
| 破坏性变更（删列/改类型） | 禁止单次发布；按多步方案执行，保留旧列直到新代码稳定 |
| 数据回填 | 回填脚本幂等可重放；必要时按备份恢复 |

发布记录：镜像 tag、迁移版本、发布时间、操作人、回滚点（对应运营端「发布交接」需求）。

## 11. 备份与恢复

| 对象 | 策略 |
|---|---|
| PostgreSQL | 每日全量 + WAL 归档（PITR）；发布前额外快照 |
| 对象存储（源视频/HLS/图示） | 桶版本化 + 生命周期规则；课程内容随 DB 元数据可定位 |
| 配置与密钥 | 密钥管理系统托管；不入库备份 |
| 恢复演练 | 季度一次：备份恢复到隔离实例并跑冒烟 |

**备份不覆盖**：学员端本机凭据（不可恢复，按设计）；模型密钥明文（不存在）。

## 12. 监控与告警

| 组 | 指标 |
|---|---|
| 服务 | 请求量/错误率/P95 延迟（按路由）、连接池、内存 |
| 队列 | 积压深度、认领延迟、任务成功率、重试率、取消率、worker 心跳 |
| 管线 | 各阶段耗时、ffmpeg 超时率、ASR 块失败率、增量段落可见延迟 |
| 生产 | 逐节九步成功率、回灌次数分布、人工待办数、评审通过率 |
| 检索 | 召回 P95、命中率、空召回率 |
| 计费 | 扣减成功率、幂等冲突数、余额分布、充值到账延迟 |
| 用量 | 各 source 的 token/图片/ASR 量、预算水位 |
| 学员侧 | 首 token P95、起播耗时、教材正文 P95 |

告警分级：P1（服务不可用/数据不一致/密钥泄露迹象/额度错扣）→ 立即；P2（队列积压、失败率升高、预算 80%）→ 工作时段；P3（单任务失败、冷却模型）→ 记录。

## 13. 运维动作清单

| 场景 | 动作 |
|---|---|
| 模型全部不可用 | 检查冷却状态 → 人工解除冷却或切备用绑定 → 通知（学员问答明确提示「暂不可用」） |
| 队列积压 | 扩 worker → 判断是否上游限流（模型/ASR）→ 必要时暂停新增生产（预算硬停同理） |
| 行情源故障 | 等待退避重试；连续失败时教材 K 线降级为「行情暂不可用」占位（不伪造），发布可继续 |
| 额度异常 | 按账本核对（只追加不修改）；必要时冲正行补偿，不改历史 |
| 内容误发布 | 回滚镜像 + 按发布记录定位；内容指纹失效应转 `approval_stale` 重新签批 |

## 14. 学员端分发

- 一键安装包（macOS Apple Silicon / Windows x64），内嵌客户端、运行时与插件；双击安装，无 Node、无命令行、无 sha256 校验等前置步骤。
- 平台覆盖如实告知（其余平台待扩展）。
- 更新：安装包重装或客户端自更新（机制待冻结）。
- 客户端与云端的契约版本门禁：低于最低支持 → 提示升级内容；高于已知上限 → 提示升级客户端，**不静默降级**。

## 15. 限流基线

单实例固定窗口（60s），键为设备 ID / IP / 后台账号 / 设备码；内存表上限 10 万键，到上限先清过期窗口，仍满则拒绝新键（避免随机键撑爆内存）。超限统一 `429` + `Retry-After: 60`，**响应体不泄露配额细节**。

| 入口 | 键 | 配置 | 默认 |
|---|---|---|---|
| 设备码申请 / 设备码换令牌 / 设备批准 | IP / 设备码 / IP | `RATE_LIMIT_DEVICE_CODE_PER_MINUTE` / `DEVICE_TOKEN` / `DEVICE_APPROVE` | 10 / 120 / 10 |
| 令牌刷新 | 设备 ID | `RATE_LIMIT_REFRESH_PER_MINUTE` | 60 |
| 后台登录 / 邀请码兑换 / 门户注册 | IP | `RATE_LIMIT_LOGIN` / `INVITE` / `REGISTER` | 10 / 10 / 5 |
| 检索 | 设备 ID | `RATE_LIMIT_SEARCH_PER_MINUTE` | 120 |
| 目录与片段读取 | 设备 ID | `RATE_LIMIT_CATALOG_PER_MINUTE` | 240 |
| 进度上报 / 事件上报 | 设备 ID | `RATE_LIMIT_PROGRESS` / `EVENTS` | 120 / 120 |
| ASR 转写 | 设备 ID | `RATE_LIMIT_ASR_PER_MINUTE` | 20 |
| 播放会话 | 设备 ID | `PLAYBACK_MAX_CONCURRENT`（并发会话数） | 5 |
| 后台内容 / 管线 | 后台账号 | `RATE_LIMIT_CONTENT` / `PIPELINE` | 300 / 30 |
| AI 运营接口 | 后台账号 | `RATE_LIMIT_AI_PER_MINUTE` | 120 |

**扩多实例前必须把限流改为共享存储**（Redis/DB），否则配额按实例放大；当前部署保持单实例。

## 16. 安全与隐私基线

| 面 | 措施 |
|---|---|
| 传输 | 全站 HTTPS；媒体域同样 TLS |
| 凭据 | 设备令牌与会话令牌只存哈希；密码只存带盐 scrypt；签名密钥与对象存储密钥走密钥管理；不入日志/响应/镜像 |
| 账号 | 后台账号由管理员创建、学员自助注册；角色最小权限；门户会话 `scope=portal` 与后台隔离；禁用/改密吊销会话，禁用即时拒绝设备令牌 |
| 门户 | 预渲染 HTML `no-store`；未知路径壳 `noindex`；公开接口只返回发布清单与聚合计数；下载强制 `attachment` |
| 内容 | 只下发 Top-K；播放地址与图示地址短时效、设备绑定（播放）或按文件限定（图示）；**不提供下载直链** |
| 内容管理 | `/v1/admin/content/*` 仅 operator/admin 会话；正文拒绝可执行 HTML/脚本；图片引用只认 `figure:<id>` 白名单格式；发布状态即时影响学员可见性 |
| 图示 | 提示词由服务端模板拼装；输出经类型/尺寸/内容校验；不生成写实行情截图与品牌标识；文件独立目录、单文件签名、不泄露本地路径 |
| 视频管线 | 上传先鉴权/限流再消费 body；`Content-Type` 与体积校验；ffmpeg/ffprobe 参数数组、**禁止 shell**；源路径/SHA/ffmpeg stderr/provider 响应不外泄；生成内容人工发布 |
| 模型密钥 | ASR、embedding、内容 LLM 密钥只存加密数据库；不序列化、不写日志/响应/镜像；内容 LLM 仅管理端调用 |
| 输入 | 白名单校验 + 长度/体积上限；拒绝非 JSON 与超大请求；ASR 路由单独 3MiB 上限并校验 WAV；上传路由单独 2GiB 流式上限 |
| 日志 | **不记 token、完整 query、完整 deviceId、源路径、转写正文、provider 响应**；排障用截断前缀或哈希；结构化日志带 `request_id`，响应回传 `request_id` |
| 隐私 | 数据最小化；事件需同意且可撤回；支持数据删除；学员语音音频与转写不落盘、不落日志、不进指标；生产不使用第三方分析 SDK |
| 额度 | 明细不含问题原文；账本只追加不修改，冲正用反向行 |

| 语料生产 | source units 幂等与批量写入、混合检索召回、概念归一（别名/自环拒绝）、目录先验校验、citations 回溯、断言证明器逐类用例、生成器确定性（重放一致） |
| 呈现层与实盘 | 标注 grounded/交易日/配额校验、`:::replay` 唯一性解析、三条回放断言证明、回放交互回归（暂停遮罩/提交锁定/揭晓含时间码/纵轴定标不跳动）、**学员作答不出现在请求/日志/validation/provenance** |
| 模型配置 | `purpose=image` 默认唯一、图片单价默认值、连通性测试、未配置时图示 503 而生成照常 |
| 门户 | 注册/登录/限流、会话 scope 越权、资料与设备解绑、预渲染深链与 `/v1` 404 语义、静态缓存头 |
| AI 运营 | 用量记账、run/steps 一致性、绑定校验、主备切换与冷却、成本缺失返回 `null`、operator 只读与 admin 写 |
| 安全 | 越权/设备不匹配/过期令牌、门户令牌访问后台、日志脱敏抽查、限流 |
| 压测 | 检索 P95 与并发目标；播放会话签发与对象存储并发 |

**CI 必跑**：类型检查 → 单元测试 → 契约测试（对 staging 或本地 compose）→ **OpenAPI 与实现一致性校验**。

**工程纪律**（沿用 trend-studio 已验证做法）：测试库守卫——`TEST_DATABASE_URL` 与 `DATABASE_URL` 必须指向不同库，同库即拦截（测试会清空目标库）；zod 等易双实例依赖全仓锁定单版本；改契约前后行为基线数字必须全绿。
