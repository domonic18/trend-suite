# 06 教材呈现与交互课件实现方案

## 第一部分 · 教材呈现层

### 1. 四层版式

教材 = 编辑部式富文本长文，由四层构成：

| 层 | 承载 | 定义 |
|---|---|---|
| 叙事层 | 富文本 DSL 容器块（目标卡 / 警示卡 / 术语边注 / 时间轴 / 对比卡 …） | §2 |
| 图示层 | 参数化 SVG 模板图示（`figures.kind=diagram`） | §3 |
| 媒体层 | 关键帧配图卡 + HLS 时间窗片段卡 | §4 |
| 实盘层 | 节级案例股清单 + K 线/成交量对照侧栏 | §5 |

**渲染同源**：管理台预览与学员端课程页使用同一套渲染组件（共享包），预览即学员渲染路径（两个消费方成立后建包，见 01 文档 §4.5）。

### 2. DSL 容器块

正文 = Markdown 子集 + 容器块。版本 `dslVersion` 只增不减，服务端同时接受已冻结版本，渲染器按版本门禁。

#### 2.1 v1 基础块

| directive | 用途 | 关键属性 | body |
|---|---|---|---|
| `:::cards` | 目标卡网格（1–4 张） | — | JSON `{items:[{num?,title,desc?}]}` |
| `:::think` | 折叠思考块（默认收起） | `title` 1–50 必填 | 文本 1–800 |
| `:::sidenote` | 术语边注（窄列注释） | `title?`、`src?`、`unitId?` | 文本 1–500 |
| `:::warn` | 警示卡（四型变体） | `title` 1–50、`variant=def\|rule\|misuse\|risk`（缺省 risk） | 文本 1–500 |
| `:::board` | 板书引用卡（教师原话） | `unitId` 必填（渲染为回溯徽章） | 引文 1–500 |
| `:::bignum` | 大数字卡（1–3 个关键数字） | — | JSON `{items:[{label,value,note?}]}` |
| `:::cmp` | 对比卡/对比表 | `mode=card\|table`（默认 card） | JSON `{title?,left:{head,items[]},right:{head,items[]}}` |
| `:::timeline` | 时间轴（3–8 事件） | — | JSON `{events:[{date,title,desc?}]}`，`date=YYYY-MM-DD` |
| `:::figure` | 配图卡（keyframe / diagram） | `figureId` 必填、`caption` 1–200、`unitId?` | 空 |
| `:::clip` | 片段卡（HLS 时间窗直放） | `assetId`、`from`、`to`（秒，整数）、`caption`、`unitId` 必填 | 空 |
| `[[stock:code\|label]]` | 个股锚（点击定位实盘侧栏） | — | — |
| `[[unit:unitId\|label]]` | 段落级证据锚（点击回溯 source unit） | — | — |

配额：`think` ≤3/节、`sidenote` ≤8/节、`cards` ≤2/节、`figure` ≤8/节、`clip` ≤3/节（超出分别 `409 *_quota_exceeded`）。

#### 2.2 v2 溯源块

| directive | 用途 | 关键属性 | body |
|---|---|---|---|
| `:::annotation` | 老师标注详情卡（原话/时间码/术语/回跳原片） | `unitId`、`assetId`、`code`、`kind=structure\|invalidation\|rhythm`、`atMs`（毫秒整数）必填 | JSON `{d,label,quote,glossary[]}` |
| `:::replay` | 正文内嵌逐根回放入口 | `code`、`caption`（1–200）必填 | 空 |

- `:::annotation` 的 `d`（`YYYY-MM-DD`）以**交易日期**定位 K 线，不用 bar 索引——行情回填分页、复权口径、窗口裁剪都会使索引漂移，日期是稳定锚点；渲染时映射 bar 索引，映射不到按「行情暂不可用」降级，**不伪造**。
- `:::replay` 渲染时解析为「本节 `type=bar-replay-decision` 且 `code` 匹配的课件」：恰一个才合法（零个 `replay_widget_unknown`、多个 `replay_widget_ambiguous`）；**DSL 不携带 widgetId**，避免正文↔课件写入顺序耦合。
- 判断点不声明在 `:::annotation`（归 `bar-replay-decision` spec），避免双份真相源。

#### 2.3 v3 质量块

v3 新增 `:::think` / `:::sidenote` / `:::cards` 三块**纯叙事组件**（不引入新引用面），并把 `:::warn` 扩为四型变体：`def` 定义（◇ 品牌色）、`rule` 要点（◆ 成功绿）、`misuse` 误用（✕ 危险红）、`risk` 风险（⚠ 警示黄）——变体只改配色与角标语义，正文形状与 v1 一致。

#### 2.4 第 2 层语义校验（随正文写入复检）

| 规则 | 错误码 |
|---|---|
| `figureId` 存在于本节图示集 | `figure_ref_unknown` |
| `unitId` 存在于本课程 source units（允许跨节引用同课程他节证据） | `unit_ref_unknown` / `unit_anchor_unknown` |
| `clip`：`0 ≤ from < to`、窗长 ≤60s、**完整落在某 source unit 时间窗内** | `clip_not_grounded` |
| `[[stock:code]]` ∈ 本节案例股清单 | `stock_not_in_list` |
| `annotation`：`atMs` 落 unit 窗内、`d` 落案例窗口内且为**实际交易日**、术语 ∈ concepts（含别名） | `annotation_not_grounded` / `annotation_date_out_of_window` / `annotation_date_not_trading_day` / `annotation_term_unknown` |
| `replay`：按 code 解析唯一回放课件 | `replay_widget_unknown` / `replay_widget_ambiguous` |

不可信文本（引文、caption、术语）渲染前转义，禁嵌套块级 Markdown 与 HTML。

### 3. 图示层：参数化 SVG 模板

- Mermaid 退出教材图示通道（渲染排版不可控）；`figures.kind='diagram'` 的 `spec = {template, params}` 由**服务端确定性渲染器**出 SVG——标注文字直出自 params，正确性 100% 由代码保证。
- 模板白名单 v1：`chip-contrast`（密集 vs 发散对比）、`chip-horizontal`（横线筹码示意）、`timeline`（时间轴示意）、`stat-inline`（大数字卡内嵌迷你图）；扩模板需冻结版本并同步渲染器。
- 第 2 层校验：`template` ∈ 白名单、`params` 过模板 schema、术语 ∈ concepts、数字性参数与所引 source unit 核对（生产端负责）、云端复检可渲染性。
- 图示写入按「同节 + 同 kind + 同 caption」覆盖更新（`figureId` 不变，正文引用不失效）；删除走显式删除端点（不可恢复，正文引用需一并改写）。

### 4. 媒体层：配图卡与片段卡

- 配图卡：`POST /v1/admin/content/sections/{sectionId}/figures` 写入；`keyframe` 由服务端从帧轨道抽帧落候选并自动选定；`diagram` 由模板渲染器确定性出 SVG；`generated` 走独立文生图通道（仅装饰）。
- 片段卡：**不预切片**，正文只存 `(assetId, fromSec, toSec)`，播放复用签名 HLS 会话；hls.js 起播 `currentTime=fromSec`，到 `toSec` 自动暂停并收起。
- 播放会话分两种签发：管理台预览（草稿可播，不要求已发布）与学员端**按节签发**（窗口须落在该节已发布正文的 clip 窗内，越窗 `409 playback_window_invalid`）。

### 5. 实盘层：案例股与行情口径

#### 5.1 案例股清单

节级清单 `section_case_stocks`：`code` / `name` / `exchange` / `period` / `window` / `events[]`。云端复检：代号格式、窗口日期合法、事件锚点 `unitId` 可回溯、`date` 落窗口内、股票名非空。

#### 5.2 行情同步与口径（声明式，渲染层不得替内容做选择）

| 项 | 口径 |
|---|---|
| 数据源 | 腾讯 `web.ifzq.gtimg.cn/appstock/app/fqkline/get`，前复权；单次 ≤640 根，向前分页回填至案例窗口起点 |
| 周期 | **日线与周线都取原生周期**（`day` / `week`），不自行聚合；周线覆盖历史远长于日线（周线约回溯至 2013–2014，日线约 2024-03）——早于 2024-03 的教学窗口必须以 `period='1w'` 声明，否则日线源取不到数据 |
| 存储 | 按周期原生缓存，唯一键 `(code, period, trade_date)`；同一代号可同时存日线与周线，重跑幂等覆盖 |
| 字段 | `volume` 单位**手**（1 手 = 100 股）；`amount`（成交额）恒 `null`（源不可得不估算）；`source='tencent-qfq'` |
| 同步 | 幂等 upsert；范围 = 课程未归档的案例股（draft + published 都取）；学员端只放行 published |
| 失败 | 单源无备用：拉取失败走任务退避重试；连续失败渲染层降级为「行情暂不可用」，**不伪造数据** |
| 声明 | 课程图示为录制时点前复权，与当前前复权存在除权漂移；K 线组件必带「不构成投资建议」与复权口径声明位 |

#### 5.3 K 线渲染契约

- 输入纯数据 `{bars:[{d,o,h,l,c,v}], events:[{date,label}], annotations?:[{d,kind,label}], window:[start,end]}`；组件自身无网络依赖，行情获取在宿主侧。
- 交互基线：K 线 + 成交量双面板、红涨绿跌、**多均线位叠加**（白名单 `M5/M10/M20/M30/M60`，默认 `M5/M10/M60`，按周期固定配色并出图例）、悬停十字线读数、滚轮缩放（光标锚定）/拖动平移、事件锚点三角标记与点选定位、案例窗口默认视野、双击复位。
- 渲染层**不做跨周期换算**：按声明周期取对应 bar。

## 第二部分 · 交互课件与断言证明

### 6. 三条铁律

| 铁律 | 含义 |
|---|---|
| **禁止 LLM 生成可执行代码** | 课件是 spec（数据），渲染由确定性 React 渲染器按 `specVersion` 执行；无生成式 h5-page 逃生舱 |
| **图表数值不由模型生成** | K 线等数值由**确定性生成器**按 spec 声明合成（`generator + seed + bars`），可重放、跨端逐字节一致 |
| **断言必须被程序证明** | spec 必带 `assertions`（教学断言）与 `citations`（source unit 引用）；服务端逐条证明并留证，**任一断言无证明记录即拒绝入库** |

### 7. 组件白名单（`widget_specs.type` 唯一合法值，扩展需冻结新契约）

| 组件 | 用途 | 关键断言 |
|---|---|---|
| `kline-annotator` | **K 线标注练习**（画趋势线/标注） | 触点数下限、斜率区间、全程不跌破、形态标签一致 |
| `pattern-quiz` | **形态识别互动题**（选图） | 答案唯一、干扰项可区分、形态与答案一致 |
| `mcq-quiz` | 概念选择题 | 答案唯一；术语 ∈ concepts |
| `step-reveal` | 分步解盘回放 | 每步结论可由该步图表状态推导 |
| `calc-trainer` | 参数化计算训练 | 公式与参数声明固定，程序复算全部示例值 |
| `flashcards` | 术语卡 | 术语 ∈ concepts；卡片数在区间 |
| `checklist` | 交互清单 | 条项非空且与节概念对齐 |
| `timeline-explorer` | 概念依赖浏览 | 边引用存在且 prerequisite 子图无环 |
| `image-juxtaposition` | 两图对比滑块（课程画面 vs 合成 K 线） | 两侧素材合法、caption 含概念名 |
| `branching-scenario` | 决策树情境练习 | 图无环、路径可达终点、最优路径连通、反馈非空 |
| `bar-replay-decision` | **真实案例股逐根回放**（先判断后揭晓） | 判断点可回溯、遮罩单调、术语有据 |

### 8. 断言词表（校验器逐条实现，记录值 `pass`；任一失败或缺失 → `409 assertion_unproven`，响应附 `failed` 数组）

| 断言 | 适用组件 | 参数 | 证明方式 |
|---|---|---|---|
| `trendlineTouches` | kline-annotator | `{min}` | 由 `solution.trendline` 两锚点 bar 索引确定直线，触及（容差 0.5×ATR）K 线数 ≥min |
| `slopeRange` | kline-annotator | `[min,max]`（角度°） | 斜率换算角度落在区间 |
| `noBreakBelow` | kline-annotator | `true` | 锚点区间内收盘价不跌破趋势线 |
| `answerUnique` | pattern-quiz / mcq-quiz | `true` | `answerId` ∈ options 且 id 唯一 |
| `distractorsDistinct` | pattern-quiz | `true` | 各选项图表形态归类互不相同且 ≠ 正确项 |
| `patternMatchesAnswer` | pattern-quiz | 生成器 id | 正确项形态归类 == 声明值 |
| `markersInRange` | step-reveal | `true` | steps 窗口单调不重叠且在 bars 范围内；markers 索引有效、价格落当根 high/low（容差 ATR） |
| `conclusionsNonEmpty` | step-reveal | `true` | 每步 `conclusion` 与 `finalConclusion` 非空（1–2000 字符） |
| `examplesRecomputable` | calc-trainer | `true` | 公式白名单实现按 `inputs` 复算，示例与 `answer` 在容差（默认 1e-6 相对）内一致 |
| `paramsInBounds` | calc-trainer | `true` | `inputs` 落在公式声明的参数域 |
| `termsInConcepts` | mcq-quiz / flashcards / checklist | `true` | 全部 `conceptRef` ∈ 本课程 `concepts`（含别名） |
| `cardCount` | flashcards | `{min,max}` | 卡片数在区间 |
| `itemsNonEmpty` | checklist | `true` | items ≥3 且每条 1–200 字符非空 |
| `edgeRefsExist` | timeline-explorer | `true` | 节点与边的 `conceptRef` ∈ concepts |
| `acyclicPrerequisite` | timeline-explorer | `true` | prerequisite 子图 DFS 无环 |
| `pairSidesValid` | image-juxtaposition | — | figureId 侧 ∈ 本节图示集；生成器侧 generator/seed/bars 合法 |
| `captionsGrounded` | image-juxtaposition | — | 两条 caption 各含至少一个概念名 |
| `graphAcyclic` | branching-scenario | — | options 构成 DAG |
| `allPathsTerminate` | branching-scenario | — | 全部路径可达终点节点 |
| `optimalPathReachable` | branching-scenario | — | 最优路径自 entry 连通 |
| `feedbackNonEmpty` | branching-scenario | — | 每 option feedback 非空 |
| `decisionPointsGrounded` | bar-replay-decision | — | 每条 decision/annotation 的 unit 存在、atMs 落窗、atDate/d 落案例窗口且为交易日 |
| `revealMonotonic` | bar-replay-decision | — | decisions[].atDate 严格递增且早于对应标注 `d`；遮罩区间单调不重叠 |
| `annotationTermsGrounded` | bar-replay-decision | — | glossary/revealText 术语 ∈ concepts 且非空 |

### 9. 生成器白名单与 spec 字段

生成器（确定性：同 `generator+seed+bars` 复算逐字节一致，服务端与渲染器同源实现）：`uptrend` / `downtrend` / `range` / `uptrend-platform` / `downtrend-platform`。参数域：`bars` 20–120；`seed` 非负整数 < 2³¹；种子化 PRNG（mulberry32）。calc-trainer 公式白名单 v1：`position-size`、`risk-reward`、`drawdown-recovery`。

**spec 包络**：`specVersion` 整数（当前 `1`）；`citations` ≥1 且必须指向存在的 source unit；`assertions` 为对象（键=断言名，值=参数）；**每类组件有必带断言**，缺失属 schema 失败（`400`）；可选断言一旦声明同样必须证明。版本只增不减；新增组件类型或破坏性字段变更必须升版本并同步冻结渲染器契约。

| 组件 | 必带断言 | spec 字段 |
|---|---|---|
| `kline-annotator` | trendlineTouches + slopeRange + noBreakBelow | `data{generator,seed,bars}`、`task`、`solution{trendline{startIdx,endIdx}}`、`annotations?[]` |
| `pattern-quiz` | answerUnique + distractorsDistinct | `data{generator,seed,bars}`（正确项）、`question`、`options[2–4]{id,label,generator?,seed?,bars?}`、`answerId` |
| `mcq-quiz` | answerUnique + termsInConcepts | `question`、`options[2–4]{id,label}`、`answerId`、`conceptRefs[]` |
| `step-reveal` | markersInRange + conclusionsNonEmpty | `data{generator,seed,bars}`、`steps[2–6]{title,fromIdx,toIdx,markers?[],conclusion}`、`finalConclusion` |
| `calc-trainer` | examplesRecomputable + paramsInBounds | `formula`（白名单）、`inputs{}`、`examples[1–10]{inputs,answer}`、`tolerance?` |
| `flashcards` | termsInConcepts + cardCount | `cards[3–20]{front,back,conceptRef}` |
| `checklist` | itemsNonEmpty | `title`、`items[3–10]{text,conceptRef?}` |
| `timeline-explorer` | edgeRefsExist + acyclicPrerequisite | `nodes[]{conceptRef}`、`edges[]{from,to,kind(prerequisite/related)}` |
| `image-juxtaposition` | pairSidesValid + captionsGrounded | `left/right` 各为 `{figureId}` 或 `{generator,seed,bars}`、`labels{left,right}`、`captions{left,right}`、`citations[]` |
| `branching-scenario` | graphAcyclic + allPathsTerminate + optimalPathReachable + feedbackNonEmpty | `scenario`、`nodes[{id,prompt,options[{label,next,feedback}]}]`、`entryId`、`optimalPath[]`、`citations[]` |
| `bar-replay-decision` | decisionPointsGrounded + revealMonotonic + annotationTermsGrounded（+ answerUnique） | `code`、`window{from,to}`、`period?`、`overlays?[]`、`annotations[]{unitId,atMs,kind,d,label}`、`decisions[]{atDate,question,options[2-4]{label},correct,revealText,unitId,atMs}`、`citations[]`；**`bars` 不入 spec**（由宿主按 §5 取，避免随行情回填漂移） |

未列字段一律拒绝；文本类字段 1–2000 字符。

### 10. 运行时契约（渲染行为，非 spec 数据）

**逐根回放（`bar-replay-decision`）—— 先判断后揭晓**

```
逐根揭示（纵轴全区间定标防跳动）
  → 到 decision.atDate 暂停并遮罩未揭示区
  → 弹判断题（2–4 选项）
  → 学员提交（答案锁定不可回改）
  → 揭晓 revealText + 老师原话 + 原片时间码（unitId+atMs 可跳回原片）
  → 继续至下一判断点
  → 结束小结（对了几处、错因在哪一步）
```

控制项：播放/暂停、单步、1×/2×、重置、进度条判断点刻度、标注按 `kind` 过滤。

**对比滑块（`image-juxtaposition`）**：两层画面叠放（上层按滑块位置裁剪），拖动比对；左侧课程画面（宿主解析 blob URL），右侧生成器合成 K 线（确定性，跨端可复现）；`labels` 作角标、`captions` 作下方说明。

**决策树（`branching-scenario`）**：逐节点作答——点选项即出该选项 `feedback`（即时反馈），点「继续」进入 `next`；到末节点给小结并对照 `optimalPath`；可重走。

### 11. 隐私护栏（硬约束）

- 学员作答只做**本地即时反馈**：不落库、不进 `validation`、不进指标事件、不随溯源上报。
- `validation` 只记录**正确答案**的程序证明。
- 若未来要做「哪一步最容易错」的统计，须另立需求并评审同意模型与字段白名单。

### 12. 写入语义与纠错回路

- `bar-replay-decision` 按 `(sectionId, spec.code)` 唯一（正文 `:::replay` 按 code 解析唯一回放课件），重复写入即覆盖（`widgetId` 不变、`version+1`；已发布行同样被覆盖——唯一性优先，内容指纹随之失效需重新审批）。
- 其余类型**不设覆盖键**：同节同类型的多份课件各自独立（一份节可挂多道不同 mcq-quiz）。
- 纠错回路是**删除端点**（草稿/已发布均可删）：写错先删旧再写新，不靠覆盖抹掉。

### 13. 渲染组件包边界与编辑边界

- 共享渲染包**不依赖管理台或学员端私有运行时**，二者只作宿主；包内 JS 不 import CSS（单文件 bundle 会炸），样式以文本导出由宿主运行时注入；组件数量超阈值时拆文件（`panel` / `player` / `citations` / `course`），纯函数优先（装配、校验、渲染分离）。
- **编辑边界**（与需求 B6 对齐）：允许表现层与措辞修改（文字、加粗/斜体/下划线、颜色、字号、对齐；图片删除/替换）；拒绝结构性修改（增删事实段、移除 `[[unit:]]` 锚、改行情数值、改 spec 结构）。保存时跑**轻校验**（锚点仍在 + 行情数值未变则通过）；触及事实锚或数值的修改被拒并提示「结构性改动走生产回灌」；任何内容变更 → 内容指纹失效 → 已签批课程转 `approval_stale`。
