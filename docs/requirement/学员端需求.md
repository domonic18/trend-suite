# 学员端需求

> **一句话**：学员装一个包、登一次录，就能对着课程提问、看视频、追案例——推理与内容都由平台供给，提问才计费。

- 读者：产品、云端开发、客户端开发
- 关联：[教师端需求](教师端需求.md) · [整体架构设计](../arch/01整体架构设计.md) · [平台服务方案](../arch/07平台服务方案.md) · [端到端流程图](../flow/student-e2e.html)

---

## 1. 谁在用，能做什么，不能做什么

**学员**（账号角色 `student`）用客户端学习课程：**推理平台供给，零配置**——注册登录即用，无需获取或配置任何模型 Key。客户端里的**伴学助手**就是插件本身：它负责课堂里的讲解呈现、追问应答与学习记录，云端负责推理与内容供给。

| 边界 | 含义 |
|---|---|
| 平台供给 · 额度计费 | 智能问答由云端推理（检索 + 生成带引用）产生，消耗额度；额度耗尽即停生成，充值续用 |
| 只读消费 | 学员只读已发布内容；写操作仅进度上报与事件同意 |
| 合规红线 | 不做实盘信号 / 荐股；回答不生成买卖建议；免责声明常驻；云端生成内容经审核过滤 |

**计费边界**：课程浏览、播放、进度、体系页、**课堂播放与随堂测验**都不耗额度；仅智能问答（含其语音转写、课堂内的讨论与自由问答）计费。

**不做的事**：学员自带模型密钥（BYOK）通道、课程售卖之外的支付场景、用户生成内容、第三方分析 SDK。

**验收尺子**：下载安装包 → 首启登录（**仅一步交互，无任何配置**）→「问得出、点得回、看得完」；额度余额与消耗始终透明。

## 2. 完整旅程

| 阶段 | 学员做什么 | 系统做什么 | 条目 |
|---|---|---|---|
| 开通 | 注册 → 下载一键安装包 → 首启登录 | 安装包内嵌运行时与客户端；设备码授权 | S1–S3 |
| 学习闭环 | 选课 → 问 / 读 / 看 | 云端推理带引用；内容消费免费 | S4–S6 |
| 持续 | 课堂、账号、额度与充值、版本更新 | 额度透明；耗尽引导充值 | S7–S9 |

## 3. 功能需求

### S1 了解与注册（P0）

- 门户公开页（预渲染、深链可刷新）：体系 / 功能 / 下载 / FAQ / 法务；**定价与额度说明页**（赠额、计费边界、充值入口）。
- 自助注册：只创建 `student`；注册即赠初始额度（数量未定）；注册即登录；按 IP 限流 + 赠额防刷策略（未定）。

### S2 安装（P0）

- **一键安装包**（官网下载）：内嵌客户端、运行时与插件，双击安装；无 Node、无命令行、无 sha256 校验等前置步骤。
- 平台覆盖如实告知（macOS Apple Silicon / Windows x64；其余平台待扩展）。
- 更新：安装包重装或客户端自更新（机制未定）。

### S3 首启登录（P0）

- 安装完成自动进入首启向导，**仅一步**：登录（注册过的账号或向导内注册）。
- 设备码授权：客户端发起 → 授权页自动拉起 → 批准后绑定设备；grant 只存本机凭据库。
- 令牌语义不变：自动轮换；设备不匹配 `403`；个人中心可解绑设备。
- **首启无任何模型配置步骤**——不需要学员提供模型密钥。

### S4 课程问答与视频溯源（P0）

- 提问（文字 / 图片 / 语音）→ 云端完成「混合检索 + 平台模型生成」→ 返回**带引用回答**；客户端渲染。
- **引用纪律**：回答只引检索返回的片段，生成端不得自造时间点；引用点击回跳播放器（seek ≤ 2s，片段高亮，播 30–60s 自动暂停）。
- **额度计费**：每次问答消耗额度（含语音转写部分）；**余额与本次消耗在界面透明可见**；额度耗尽返回明确错误（非静默失败）并提示充值入口；检索命中列表与**内容浏览不受额度影响**。
- 空召回：明确「课程未覆盖」并给最近知识点（≤5，仅标题），禁止编造。

### S5 体系浏览与富媒体学习（P0，不耗额度）

- 体系页课程树（懒加载、不含正文与起止秒）；**富媒体课程页**（与管理台同构渲染：正文 DSL / 图示 / 片段卡 / 案例股面板）。
- 片段播放按节签发签名会话，窗校验越窗拒绝；行情未同步显占位；**内容消费（浏览 / 播放 / 进度）不扣额度**；案例股 K 线面板按节声明周期（日线 1d / 周线 1w）展示并支持切换，复权口径声明常驻。
- 数据边界：草稿与未发布内容不可见；逐根回放作答只在本机。
- 学习进度：幂等、时长取最大、完成不回退。

### S6 学习场景即时提问（P0/P1）

- 文字 / 图片提问：选中即问；自动上下文默认开、可关，**只在本机内存**，不上云。
- 语音提问：≤ 60s；浏览器采集 → 云端 ASR → 文本插入输入框待确认；**转写计入额度**；音频仅内存流转，不落盘不进日志。

### S7 互动课堂（P1：课堂播放不耗额度 · 增强互动耗额度）

**场景**：学员在课程页点「进入课堂」，像听一节直播课那样学这一节——有人讲、有人问、有图可点、有题可答、有原片可回看。

**前置**：该节已发布，且教师在生产阶段为它编排了课堂内容（讲解稿、白板脚本、引导点、随堂测验、互动课件）。

**课堂骨架**：一节课 = 若干**场景**顺序播放，四种场景类型：

| 场景类型 | 课堂里看到什么 | 内容来源 |
|---|---|---|
| 讲解页 | 正文 + 图示 + **讲解音轨**，讲解时聚光灯 / 激光笔跟随高亮 | 教材正文与关键帧 + 生产阶段生成的讲解稿 |
| 随堂测验 | 单选 / 多选 / 简答，**提交即判分并给反馈** | 生产阶段产出的测验题 |
| 交互课件 | 组件白名单里的互动组件（K 线标注、形态识别、逐根回放、对比滑块、决策树…） | 教材内的互动课件 |
| 项目制练习 | 案例股逐根回放：**先判断后揭晓** | `bar-replay-decision` 组件 |

**播放轨道**：课堂播放由一串「动作」驱动。基础课堂的动作**全部预生成、本地播放**，不调云端：

| 动作 | 课堂效果 |
|---|---|
| 讲解 | 播放讲解音轨（本地语音合成，语速 / 音色可选），字幕同步显示 |
| 聚光灯 / 激光笔 | 跟随讲解高亮页面元素、其余变暗；激光笔指向指定元素 |
| 白板 | 打开共享白板并逐笔画出：文字、图形、图表、公式、表格、代码；可擦除、可关闭 |
| 片段播放 | 播放课程原片片段（签名会话，与 S5 同一条链路） |
| 组件引导 | 在交互课件上高亮元素、设置状态、留标注（引导点由教师预置） |

**AI 教师引导**：讲解到关键处自动高亮该看的区域、给出提示、把学员注意力引到该看的地方——引导点在生产阶段预置，课堂里不实时决策。

**增强互动（显式开启，耗额度）**：

| 形态 | 课堂里发生什么 |
|---|---|
| 课堂讨论 | AI 同学主动抛出讨论话题，学员可加入，也可被点名 |
| 圆桌辩论 | 多角色人设（如多空双方）围绕话题辩论，配合白板讲解 |
| 自由问答 | 随时向伴学助手提问，答案**带引用可回跳原片**（走 S4 同一条问答链路） |

**计费边界**：课堂播放、随堂测验、本地判分、复习清单**不耗额度**；增强互动走问答链路**计费**，发起前界面明示本次消耗。

**预期结果**：
- 断网或额度耗尽时，基础课堂仍可完整播放（内容与讲解音轨已在本地）
- 随堂测验本地判分，即时给出对错与解析；错题进入本节复习清单
- 增强互动消耗额度时，余额与本次消耗实时可见（同 S4）
- 课堂进度计入学习进度，可中断续播

> **对标**：本节的多智能体课堂模型（场景类型、动作词表、讨论与辩论人设）参考开源项目 [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)（MIT）的互动课堂契约。与它的差异：本项目的课堂内容是**发布前生产好的**（OpenMAIC 是按需即时生成），因此基础课堂不调云端、不耗额度。

### S8 账号、额度与充值（P0）

- 个人中心：改密、设备管理与解绑、注销。
- **额度中心**：当前余额、消耗明细（时间 / 问题维度摘要，不含问题原文）、赠额记录、充值入口。
- **充值**：点数包或订阅（定价与档位未定）；支付渠道（微信 / 支付宝，未定）；支付成功额度即时到账；发票与退款规则未定。
- 指标上报默认关闭、可撤回；学习上下文永不进指标。

### S9 更新与版本兼容（P1）

- 内容契约版本门禁：低于插件最低支持提示升级内容、高于已知上限提示升级客户端，不静默降级。
- 客户端更新：一键安装包重装（自更新未定）。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 检索 P95 ≤ 300ms；问答首 token P95 ≤ 3s（平台模型）；起播 ≤ 2s；教材正文 P95 ≤ 1.5s；语音端到端 P95 ≤ 5s |
| 成本 | 推理成本平台全额承担；**额度定价须覆盖单位成本**（按模型单价配置估算）；预算与调价机制未定 |
| 防滥用 | 按账号 / 设备限流；赠额防刷（注册门槛 + 异常识别，策略未定）；额度扣减幂等（防重放） |
| 安全 | 签名 HLS + 设备绑定 + 水印；云端生成内容按不可信数据处理并过滤（提示注入、违规内容）；支付链路安全 |
| 隐私 | 音频与转写仅内存；日志脱敏；额度明细不含问题原文；数据最小化、支持注销 |
| 合规 | 云端生成内容审核；投资内容常驻免责声明；生成式服务备案；支付合规 |

## 5. 验收标准

| 场景 | 用例 | 期望 |
|---|---|---|
| 开通 | 全新机器下载安装包 → 首启 | 一步登录后即可提问；全程零配置、零命令行 |
| 额度 | 正常问答 | 回答带引用；界面显示余额与本次消耗；账本可查 |
| 额度 | 余额耗尽后再问 | 明确「额度不足」提示 + 充值入口；不静默失败；检索与课程浏览照常 |
| 额度 | 充值到账 | 支付成功额度即时恢复；重复回调不重复加额 |
| 计费边界 | 纯浏览 / 播放 / 课堂 | 不消耗额度 |
| 课堂 | 进入课堂并播放 | 讲解音轨与动作本地播放，无云端调用；断网可完整播放 |
| 课堂 | 随堂测验提交 | 本地判分即时给对错与解析；错题进本节复习清单；不耗额度 |
| 课堂 | 开启讨论 / 自由问答 | 走问答链路返回带引用答案；发起前明示本次消耗；余额实时可见 |
| 课堂 | 讲解中的引导动作 | 聚光灯 / 激光笔跟随讲解高亮；白板按脚本逐笔绘制 |
| 防滥用 | 高频问答 / 异常注册 | 限流 429；赠额防刷策略生效 |
| 引用 | 点击引用 | 回跳成功率 ≥ 99%，seek ≤ 2s |
| 拒答 | 课程未覆盖 | 拒答率 100%；给最近知识点 |

## 6. 平台约束

客户端形态保留（一键安装包）；其余平台约束继续约束客户端实现：Remote 注入顺序、右栏 tab、自定义 scheme 不可点 → 引用走片段 ID 主路径、HTTP Range、peer 锁版、credentials 时序。

## 7. 未定项（需产品确认）

| 事项 | 起始值 | 影响 |
|---|---|---|
| 赠额数量与定价 | 按单位成本 × 目标毛利标定（试产期观察） | 商业模型 |
| 计费粒度 | 按次起步，token 粒度后置 | 计费公平性 |
| 支付渠道与档位 | 微信 / 支付宝点数包 + 订阅 | 充值链路 |
| 赠额防刷策略 | 注册门槛 + 设备维度克制设计（守隐私边界） | 滥用成本 |
| 客户端自更新 | 后置（先安装包重装） | 更新体验 |
| 发票 / 退款规则 | 后置 | 合规 |
| 课堂讲解音轨的合成方式 | 本地语音合成起步（不调云端、不耗额度） | 音质与设备算力 |
| 圆桌辩论的人设与角色数 | 先做 2 个角色（多空双方） | 讨论体验与算力成本 |
