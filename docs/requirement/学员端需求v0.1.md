## 1. 角色定义与边界

**学员**（账号角色 `student`）：在本地 dsh 客户端 + 伴学插件中学习课程；**推理走学员自己的模型（BYOK）**，云端只提供课程知识与内容服务。

| 边界铁律 | 说明 |
|---|---|
| 云端不做推理 | 无 Key 学员不在支持范围；平台不发兜底 Key |
| 只读消费 | 学员只读已发布内容；写操作仅进度上报与事件同意 |
| 合规红线 | 不做实盘信号 / 荐股；回答不生成买卖建议；免责声明常驻 |

**非目标**：课程售卖与支付、UGC 课程生产、第三方分析 SDK。

**总体验收尺子**：技术型学员照门户向导**十分钟内**完成安装与授权，随后「问得出、点得回、看得完」。

## 2. 端到端旅程（需求主线）

| 阶段 | 学员做什么 | 系统保障 | 主要条目 |
|---|---|---|---|
| 0 了解注册 | 逛门户、注册 | 预渲染公开页 + 自助注册 | S1 |
| 1 环境准备 | 装 Node.js 22+、备模型 Key | 向导分 OS 逐步指引 | S2 |
| 2 安装插件 | 下载 tgz → 装插件 → 启动 | 版本精确匹配；排错兜底 | S2 |
| 3 配置授权 | 配模型、设备登录 | 设备码授权绑定账号 | S3 |
| 4 学习闭环 | 体系页 → 课程页 → 问 / 查 / 播 / 练 | 检索 + 签名播放 + 富媒体渲染 | S4–S7 |
| 5 持续使用 | 更新、管账号与隐私 | 版本门禁 + 个人中心 | S8–S9 |

## 3. 功能需求

### S1 了解与注册（P0）

- 门户公开页（预渲染、深链可刷新、未知路径回落壳并 noindex）：首页 / 体系 / 功能 / 安装向导 / 下载 / FAQ / 法务。
- 自助注册：只创建 `student`；用户名 3–32（小写字母开头 `[a-z0-9._-]`）+ 密码 10–128；注册即登录；冲突 409；按 IP 限流。
- 发布清单与统计为公开只读接口（60s 缓存）；下载文件以附件形式提供。
- 不提供邮箱验证与找回密码（忘记密码走管理员重置）。

### S2 环境准备与安装（P0）

- 前置：Windows 10/11（64 位）或 macOS 12+；Node.js ≥ 22；自备模型 API Key（DeepSeek 官方或 OpenAI/Anthropic 兼容端点）。
- **安装向导**（门户 `/guide`，按 OS 分步）：检查电脑版本 → 装 Node.js → `node -v` 验证 → 下载插件 tgz（不解压不改名）→ 安装插件命令（workspace 需 `-w`；dsh 版本与清单**精确一致**）→ 安装网页界面（推荐，可跳过）→ 启动客户端（本机 Web UI）→ 登录授权。
- 向导每步给出：要点哪里、粘贴什么、会看到什么；安装排错 FAQ 覆盖高发卡点（node 未装、浏览器自动解压、peer 版本不匹配、profile 不存在、Web UI 缺失、视频无法播放）。
- 平台边界如实告知：官方桌面包仅 macOS Apple Silicon / Windows x64。

### S3 配置与授权（P0）

- BYOK 模型配置：在 dsh 设置页配置 provider + API Key（凭据只存本机）；回答质量取决于学员模型，不达标时提示更换。
- **设备码授权**：插件面板「设备登录」发起 → 展示用户码与授权页地址并轮询 → 学员在授权页用本站账号登录、核对数字后批准 → 设备绑定账号；授权码有时效，过期重发。
- 令牌语义：业务请求带 Bearer + 设备 ID；缺失/过期 401、设备不匹配 403；**自动轮换**（access 过期用 refresh 换新，旧 refresh 立即失效）；grant 只存本机凭据库（600），不进浏览器、日志、配置。
- 设备管理：个人中心可查看与解绑本人设备。

### S4 课程问答与视频溯源（P0）

- 检索：自然语言提问 → 云端 Top-K 片段（K ≤ 20，默认 5）→ 学员本地模型基于检索结果作答；查询 1–500 字符；单次响应 ≤ 512KiB、单片段文本 ≤ 4000 字符。
- **引用纪律**：回答只引用云端返回的片段 ID，模型**不得自行生成时间点**；每条回答附「课程 → 章节 → 知识点 → 时间点」出处。
- 引用回跳：点击回答中的片段 ID 代码块 → 播放器 seek 到权威起止秒（误差 ≤ 2s），片段内高亮、播 30–60s 自动暂停；历史回答中的引用随时可点。
- 空召回：明确回答「课程未覆盖」并给出 ≤ 5 个最近知识点（仅标题），**禁止编造**。
- 签名播放：短时效签名 HLS（m3u8 内 key 与分片同 token）；媒体域 CORS + HTTP Range；过期给可读提示不静默黑屏；播放画面叠加用户水印。

### S5 体系浏览与富媒体学习（P0）

- 体系页：课程 → 章节 → 知识点树 + 学习路径与完成状态；目录**不携带**起止秒与正文（懒加载）。
- **富媒体课程页**（整本课程阅读载体，与管理台预览同一套渲染组件，所见即最终效果）：目录条（章/节锚点）→ 节头（概念 / 标题 / 导语）→ 正文（版式块 / 图示 / 片段卡 / 老师标注 / 回放入口）→ 案例股面板（K 线 + 成交量 + 事件锚点）。
- 片段播放按节签发会话，**播放窗必须落在该节已发布正文的片段窗内**，越窗被云端拒绝并提示，不静默错播。
- 案例股行情未同步时显示「等待行情同步」占位，不伪造数据；展示携带复权口径声明与「不构成投资建议」。
- 数据边界：未发布章节 / 图示 / 案例股 / 草稿内容对学员**一律不可见**；无已发布节时如实提示不出空白页。
- 逐根回放判断练习：先判断后揭晓老师结论；**作答只在本机反馈**，不采集、不上报、不进进度。
- 学习进度：观看时长与完成状态上报（`watchedSec` 取历史最大、`completed` 不回退、幂等）；进度是业务写入，不受指标同意开关影响。

### S6 学习场景即时提问（P0/P1）

- 文字 / 图片（M4.1，P0）：选中正文即可提问；图片复用平台原生附件与学员模型视觉能力，插件**不接收、不存储、不转发**图片二进制。
- 自动上下文：当前课程 / 章节 / 播放位置 / 选中文本默认自动携带、可一键关闭；上下文**只在本机内存**处理，不上云、不落日志、不进指标。
- 语音（M4.2，P0）：输入框常驻麦克风按钮；单次录音 ≤ 60s；浏览器采集重采样 16kHz 单声道 WAV → 云端 ASR 转写 → **文本插入输入框待确认，不自动发送**；音频与转写只在内存流转，不落盘、不进日志；未识别 / 无权限 / 限流等给可读中文提示，不自动重试。

### S7 互动课堂与随堂测验（P1）

- 单师课堂：AI 教师基于已发布教材开讲（本地语音合成，零服务端成本），支持暂停 / 追问 / 跳章；白板与 K 线图表标注同步讲解。
- 随堂测验：章节题库（3–5 题）静态下发、本地即时评分与解析；错题进复习清单；测验独立于讲解可随时重做。
- 课堂结束生成学习小结与待复习知识点。

### S8 账号管理与隐私（P0）

- 个人中心：改密（吊销其他会话）、设备列表与解绑、注销。
- 指标上报**默认关闭**：学员显式同意后开启、可随时撤回；字段白名单（检索 / 引用点击 / 起播 / 反馈评分），不含问题原文、回答内容、完整设备 ID、播放地址。
- 学习上下文（播放位置 / 选中文本等）永不进入任何指标。

### S9 更新与版本兼容（P1）

- 插件更新：门户下载新 tgz → 重装 → 重启；当前无自动更新与灰度。
- 内容契约门禁：课程树携带契约版本；低于插件最低支持提示升级内容、高于已知上限提示升级插件，**均不静默降级**。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 云端检索 P95 ≤ 300ms；视频起播 ≤ 2s（CDN）；教材正文（不含图片）P95 ≤ 1.5s，图片懒加载；语音端到端（不含学员输入）P95 ≤ 5s |
| 可用性 | 知识与视频服务 ≥ 99.5%；本地模型故障给可读提示 |
| 安全 | 签名 HLS + 设备绑定 + 并发限制；云端内容按不可信数据隔离（防提示注入）；图示只加载章节响应内的签名 URL，外链一律不请求；禁直链与整片下载 |
| 隐私 | 音频与转写不落盘不进日志；日志脱敏（不记 token / 完整 query / 完整设备 ID）；数据最小化、支持注销 |
| 合规 | 投资内容常驻风险提示与免责声明；回答不生成买卖建议；生成式服务合规公测前确认 |
| 成本 | ASR 按时长计费且限流防滥用；推理成本学员承担（BYOK） |

## 5. 验收标准

| 类别 | 用例 | 期望 |
|---|---|---|
| 注册 | 正常 / 重复用户名 / 弱密码 / 限流 | 201 自动登录 / 409 / 400 / 429 |
| 安装 | 全新机器照向导操作 | 十分钟内完成安装与授权；侧栏出现伴学面板 |
| 授权 | 设备码发起 → 批准 → 重启客户端 | 登录态保持；设备绑定；错设备 403 |
| 问答 | 正常提问 | 引用命中率 ≥ 90%（抽检 100 条）；首 token P95 ≤ 3s（基准模型） |
| 问答 | 课程未覆盖 | 拒答率 100% 不臆造；给最近知识点（仅标题） |
| 溯源 | 点击引用 | 跳转成功率 ≥ 99%；seek 误差 ≤ 2s；片段高亮 |
| 播放 | 签名过期 / 越权 / 越窗 | 可读提示不黑屏；越窗播放被拒并提示 |
| 课程页 | 渲染一致性 / 草稿隔离 | 与管理台预览逐块一致；任何草稿内容不出现 |
| 语音 | 安静环境普通话 | 转写准确率 ≥ 90%（抽检 50 条）；插入输入框未自动发送；取消不产生请求 |
| 进度 | 重复 / 乱序上报 | 幂等；时长取最大；完成不回退；非本人设备 403 |
| 隐私 | 日志与网络检查 | 无音频、转写正文、token、完整设备 ID；上下文不出本机 |

## 6. 平台约束（dsh，编号基线）

学员端运行于 dsh（web 应用面）。关键约束：Remote 服务注入顺序（先 mount 后 inject，写静态 inject 死锁）；右栏 tab 注册形状（数组 + keyed slot）；**自定义 scheme 链接不可点**（引用走片段 ID 代码块主路径 + 链接拦截备选）；播放器要求服务端 HTTP Range；peer 版本精确锁定；credentials 服务须与 tools 一起静态注入；Web UI 无 CSP（升级需复验，收紧则图示改 Host 代理）。
