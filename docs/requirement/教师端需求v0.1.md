## 1. 角色定义与边界

**教师**（课件制作人员，账号角色 `producer`）：在本机 dsh（web 应用面）中驱动「语料级视频 → 图文课程 + 交互课件」的生产会话；审批两道人工门禁。

| 边界铁律 | 说明 |
|---|---|
| 只写草稿 | 教师的一切写入均为 `draft`；签批与发布是运营（operator/admin）动作 |
| 模型自备 | 模型 API Key（含 VLM 理解）教师自配，只落本机 dsh 凭据库，不经云端 |
| 结构不发明 | 课程目录以人工目录为先验骨架，Agent 只做校验与归一 |

**总体验收尺子**：新教师拿到「插件包 + 模型 API Key + 云端账号」**三步装完**；全程只在三个决策点被打断（门禁①骨架放行 / 评审 reject 要不要改 / 追加素材怎么处理）。

## 2. 端到端旅程（需求主线）

| 阶段 | 教师做什么 | 系统保障 | 主要条目 |
|---|---|---|---|
| 0 前置 | 领账号、备模型 Key | 账号体系 | A1 |
| 1 下载安装 | 一条命令装机 → 面板登录 → 贴密钥 | 九项自检；机密后置 | A2 |
| 2 素材入库 | 拖视频、说意图 | 直传通道（字节不经插件）；增量转写 | A3 |
| 3 骨架门禁① | 确认目录/概念/术语 | 目录先验 | A4 |
| 4 逐节生产 | 三个决策点外全自动 | 九步引擎；三层校验；断点续跑 | A5 |
| 5 交接发布 | 看就绪度卡片，等运营签批 | 五道门禁一份实现 | A6 |
| 6 日常运维 | 更新 / 排障 | doctor 自检 | A7 |

## 3. 功能需求

### A1 账号与前置（P0）

- 管理员创建 `producer` 账号：密码（scrypt 哈希）或一次性邀请码（单次有效、只存哈希）。
- 教师自备模型 API Key；密钥只写本机 dsh 托管凭据库（权限 600），不进配置文件、不上云。
- 机器前置：macOS / Windows、Node ≥ 22、dsh 版本与门户清单精确一致。

### A2 下载与安装（P0）

- 门户教师页（`/teacher`，公开）：前置条件、安装命令、装完检查清单、生产顺序说明、更新与卸载。
- 发布清单含生产端插件条目（文件名 / sha256 / 大小 / 发布说明），学员侧契约零变化。
- **一键安装**：`curl -fsSL <站点>/install-<插件>.sh | bash`——脚本查发布清单 → 下载 → 现场 sha256 比对 → 解包 → 零提问装机 → 自动自检；非交互环境显式报错不做无声降级。
- 安装包自带：全部 Skill 工艺包、装机脚本、契约依赖 bundle；**下载即装，不碰仓库、不改配置文件**；重装不依赖下载目录（包归档进 profile）。
- **九项装机自检**（任一不过当场报红并给可执行下一步）：凭据库权限 / 插件版本与安装包一致 / 技能包挂载数量与位置 / 技能链路启用 / 应用面（web 界面）/ 模型位唯一 / 模型可达（真发一次最小请求）/ 云端可达 / 登录态且角色为 producer。未登录、未贴密钥报**待办**而非失败。
- 装完后置两步（都在 dsh 界面里）：右侧栏生产面板点「登录」→ 浏览器自开云端授权页（教员端授权，批准后令牌热生效）；设置页粘贴模型密钥（热生效）。
- 备用命令面：`/trend login`、`/trend status`（面板不可用时功能等价）。

### A3 素材入库（P0）

- 拖视频进会话 → **五步直传**：建素材 → 签发直传凭据 → 字节直传云端（**不经插件进程**）→ 落库确认 → 入队转写。凭据 HMAC 签名绑定「素材 + 字节数 + 摘要 + 有效期」，一张票只对一份字节。
- 素材边界：单文件 ≤ 2GiB；必须同时有视频流与音频流，否则拒绝并清理半成品。
- **增量转写**：每转完一块即落可读段落（`partial` 标记），理解与生产可提前起跑；关键帧轨道先于转写完成。
- **追加素材三选一**（课程做到一半再拖视频）：A 只补这节 / B 重做课程骨架 / C 只入库暂不生产——**先只读算影响面（哪些节会被重评）再让教师确认**；决策持久化；受影响节的生产步骤重置（回灌预算保留）。
- 教师可建课程 / 章 / 节 / 测验 / 素材并直传入队（写入恒为 draft）；**不可**：归档素材、改课程状态、签批、发布。

### A4 课程骨架与门禁①（P0）

- **目录先验**：以人工目录（或教师口述目录）为骨架，目录外内容不创建；章 ID 可读回，不靠猜。
- 概念归一：术语入概念表（含别名）与依赖边；术语名成为正文与课件校验基准；重复名 / 自环边拒绝。
- **门禁①**：骨架 + 概念图谱 + 术语表经教师在 dsh 内批准后方可逐节生产；云端不重复强制。

### A5 逐节生产（P0，约占全程 90% 时间）

- **九步固定顺序（引擎强制，跑错序被挡并提示「当前该做第几步」）**：
  `案例股 → 行情同步 → 行情读回 → 图示 → 回放课件 → 正文 → 其余课件 → 评审 → 溯源`
  顺序由依赖倒推（正文个股锚要求案例股在册；标注日期必须是行情缓存真实交易日；正文图示引用要求图示属本节；回放按代码解析唯一课件）。
- 教材正文：Markdown 扩展 DSL（版式容器块 + 段落级 `[[unit:]]` 证据锚 + 个股 `[[stock:]]` 锚）；**grounded 纪律**：事实段落必须可回溯 source unit，无出处断言校验拒绝。
- 图示三路分工：源视频关键帧 / 参数化 SVG 模板（服务端确定性渲染，标注文字必须正确）/ 文生图仅装饰不承载教学信息；节级配额；同节同题覆盖更新 + **删除纠错回路**。
- 交互课件：白名单组件（JSON spec + 断言），数据由确定性生成器合成（seed 可重放），服务端断言证明缺一拒绝入库；**禁止 LLM 生成可执行代码**；作答类组件学员侧只做本地反馈。
- 案例股与行情：节级案例股清单（名称 / 交易所代号 / 案例窗口 / 事件锚点）云端复检；行情按声明周期取原生序列（日线 / 周线分存）。
- **三层校验收敛**：① schema（工具边界 + 云端复检）→ ② 语义（断言证明 / 术语 ∈ 概念表 / 引用可回溯 / 媒体锚点对位）→ ③ 教学质量（rubric 结构化评分，grounded 含「行情数值可核」一票否决）。失败回灌重写 ≤ 3 次，仍失败进人工待办，**绝不部分落库**。
- **断点续跑**：云 DB 即 checkpoint，中断重开按缺失单元续跑，不依赖本地状态。
- 生产看板：每节一行九步状态 + 产出计数 + 最近评审结论 + 追加素材决策；「当前步」口径与引擎一致；流程向导（每步目标 / 工具 / 常见坑）。
- 评审门禁②：主编按 rubric 评分，verdict approve / reject；reject 可回灌。

### A6 交接与发布可见性（P0）

- **发布就绪度**（只读，教师可看）：五道门禁逐条判定（图示解析 / 课件断言证明 / 片段窗 / 标注与回放 / 终审签批）+ 当前内容指纹 + 待办清单；**门禁判定一份实现**——就绪度与发布读同一批检查结果，不会「全绿点发布还 409」。
- 结构化内容编辑（写恒为 draft）：节元数据 / 案例股清单 / 术语（归档而非删除，可逆）三个编辑入口；**正文 DSL 不在管理台手改**（绕过行情交易日与术语校验），改正文走生产端回灌。
- 内容指纹覆盖一切会被发布的内容；改内容即已签批失效（`approval_stale`），必须重签。
- 签批与发布按钮**对教师隐藏**（分权不靠点下去吃 403）。

### A7 日常运维（P1）

- 更新：重新下载新版本安装包 → 重跑装机（旧版自动归档）；安装包内容实质变化必须升版本。
- 令牌过期（12h）：面板点「登录」重登即热生效，无需重启。
- 错误分流：401（会话失效 → 重登）/ 403（角色不足 → 找运营），工具错误文案附可执行指引。
- 卸载：删 profile 目录；凭据条目手动清理。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 安全 | 机密只存托管凭据库（600）；不注册 shell / 文件写入工具；云端文本按不可信数据处理（边界转义） |
| 稳定性 | 长任务可中断恢复（云 DB checkpoint）；编排步数与回灌预算上限；校验失败不静默 |
| 契约 | 接口字段与云端对接清单一致；出参入参双向校验，契约测试守卫 |
| 可观测 | 每个落库产物上报溯源（任务 / 模型 / token / 耗时 / 工艺包版本）；不记密钥与产物正文 |

## 5. 验收标准

| 类别 | 用例 | 期望 |
|---|---|---|
| 安装 | 全新环境解包官网安装包装机 | 工艺包落进 profile 内且计数正确；九项自检全绿；版本「与安装包一致」 |
| 安装 | 凭据库权限非 600 | 自检当场报红并给修复命令，不等启动时报错 |
| 面板 | 启动后右侧栏生产面板 | 四张卡片（登录 / 模型密钥 / 云端 / 生产看板）；点「登录」浏览器授权、令牌热生效 |
| 素材 | 拖入视频 → 直传 → 转写 | 字节不经插件进程；转写未完即可读部分段落（`partial=true`） |
| 素材 | 追加素材选 A/B/C | 影响面先只读展示；决策入库；受影响节步骤重置而回灌预算保留 |
| 骨架 | 门禁① | 目录外章节不被创建；概念重名 409；审批后逐节解锁 |
| 生产 | 九步跑错序 | 引擎报错并指出「当前该做第几步」 |
| 生产 | 单章全量 | 节教材 + 图示 + 课件全量通过三层校验入 draft；失败回灌 ≤3，绝不部分落库 |
| 交接 | 就绪度卡片 | 五道门禁与发布事务同源判定；内容变更后指纹失效转待重签 |
| 分权 | 教师调签批 / 发布端点 | `403`；管理台不显示签批发布入口 |

## 6. 平台约束（dsh，编号基线）

教师端运行于 dsh（web 应用面）。关键约束（完整基线见架构文档）：凭据库权限 600 否则拒载；peer 版本精确锁定；技能包目录挂载（缺目录静默丢包）；web 应用面会禁用技能链路需装机显式置回；授权流一次尝试存活于发起进程（过期重登）；附件机制（任意文件入会话、模型收路径）。每次升级 dsh 必须跑兼容复验清单。
