## 1. 角色定义与边界

**教师**（课件制作人员，账号角色 `producer`）：**浏览器用户**——打开生产工作台即可制作课件；无本地安装、无模型密钥、无运行时运维。

| 边界铁律 | 说明 |
|---|---|
| 只写草稿 | 教师的一切写入均为 `draft`；签批与发布是运营（operator/admin）动作 |
| 模型云端预置 | 生产所用模型（含 VLM 理解）由运营在模型配置页维护（加密存储、任务级主备绑定）；教师零密钥 |
| 结构不发明 | 课程目录以人工目录为先验骨架，Agent 只做校验与归一 |

**总体验收尺子**：新教师拿到账号，**打开浏览器即可制作第一节课**；全程只在三个决策点被打断（门禁①骨架放行 / 评审 reject 要不要改 / 追加素材怎么处理）。

## 2. 端到端旅程（四阶段）

| 阶段 | 教师做什么 | 系统保障 | 主要条目 |
|---|---|---|---|
| B1 账号与预置 | 无（管理员建号、运营配模型） | 账号体系 + 模型配置 | B1 |
| B2 素材与骨架 | 登录工作台、建课、拖视频、批门禁① | 浏览器直传；增量转写；目录先验 | B2 |
| B3 逐节生产 | 三个决策点外全自动 | 云端 worker 九步引擎；断点续跑；看板 | B3 |
| B4 交接与发布 | 就地微调教材（文字/样式/图片/K 线属性），看就绪度，等运营签批发布 | 五道门禁一份实现；轻量编辑仍受校验边界约束 | B4 · B6 |

（v0.1 的 A1 自备 Key、A2 下载安装、A7 日常运维三个阶段整体消失；运维归云端。）

## 3. 功能需求

### B1 账号与模型预置（P0）

- 管理员创建 `producer` 账号：密码（scrypt 哈希）或一次性邀请码（单次有效）。
- 运营在模型配置页预置生产模型：LLM/VLM/ASR 条目（密钥 AES-GCM 加密、仅管理端维护）、任务级主备绑定、连通性测试；**明文不进浏览器、日志与响应**。
- 教师侧要求仅为：现代浏览器（Chrome / Edge / Safari），可上传大文件（直传通道，见 B2）。

### B2 素材入库与课程骨架（P0）

- 登录生产工作台（Web 会话，`producer` 角色专属入口；学员不可见）。
- **浏览器直传**：工作台内建课 / 选课后拖入视频 → 建素材 → 签发直传凭据（HMAC 绑定素材+字节数+摘要+有效期）→ **浏览器直接 PUT 字节到云端存储** → 落库确认 → 入队转写。单文件 ≤ 2GiB；必须同时有视频流与音频流，否则拒绝并清理半成品；上传进度可见、可重试。
- **增量转写**：每转完一块即落可读段落（`partial` 标记），理解与生产提前起跑；关键帧轨道先于转写完成。
- **课程综合**：目录先验（人工目录为骨架，目录外内容不创建）；概念归一（术语入概念表含别名、依赖边，重复名/自环拒绝）。
- **触发方案制作（显式触发）**：素材随上传自动流水处理（单 / 批皆可）；方案由教师在工作台**显式触发**——选择素材集、提交课程目标与目录先验（可粘贴 / 口述）后点「生成制作方案」；触发时预检所选素材就绪度（ready 或明确允许 partial）。**Agent 不从上传行为推断课程边界**。
- **门禁①（方案确认，三个动作）**：骨架 + 概念图谱 + 术语表 + 分节计划经教师确认后逐节生产解锁。审批组件提供：
  - **批准**：方案锁定为基准版，解锁逐节生产；
  - **微调**：直接结构化编辑方案条目（章节增删合并 / 改名 / 概念别名 / 分节粒度），即时生效；
  - **打回**：给自然语言修改指令 → 综合 Agent 基于已有 source units **重起草**（不重跑素材理解，秒级返回新草案）。
  - **版本历史**：方案草案与人工修改留版本轨迹（v1 → v2 …），可追溯；确认后锁定，中途变更走「追加素材 B 重做骨架」。
- **追加素材三选一**（课程做到一半再拖视频）：A 只补这节 / B 重做课程骨架 / C 只入库暂不生产——工作台**先只读展示影响面（哪些节会被重评）**再让教师确认；决策持久化；受影响节生产步骤重置（回灌预算保留）。

### B3 逐节生产（P0，约占全程 90% 时间）

- **Agent 编排（四角色）**：生产由云端 Agent 链承载，工具调用与确定性校验落云端服务——
  | 角色 | 职责 |
  |---|---|
  | 理解 Agent | 多模态逐 chunk 处理素材（转写分组 + 采样帧），产出 source units；随素材就绪自动运行 |
  | 综合 Agent | 目录先验校验、概念归一、起草制作方案（含分节计划）；支持打回重起草（复用 units） |
  | 逐节子代理 ×N | 每节一个并行子代理，按九步固定顺序生产（案例股 → 行情同步 → 行情读回 → 图示 → 回放课件 → 正文 → 其余课件 → 评审 → 溯源）；**引擎强制顺序**（跑错序被挡并提示当前步）；断点续跑（云 DB 即 checkpoint，worker 崩溃恢复不依赖本地状态）；并行度有上限 |
  | 评审 Agent | rubric 十维自评（grounded 含行情数值可核一票否决），生成逐段修改指令 |
- **人工待办中心**：回灌超限（≤3 次未收敛）、概念归一冲突等显式待办进入工作台待办区，绝不静默丢弃。
- 教材正文：Markdown 扩展 DSL + `[[unit:]]`/`[[stock:]]` 锚；**grounded 纪律**不变（事实段落必须可回溯 source unit）。
- 图示三路（diagram / keyframe / generated，配额与禁止承载教学信息）、课件白名单 + 断言证明（11 类组件、断言词表、确定性生成器）、案例股与行情口径（腾讯前复权、周期原生日/周 K、均线位白名单、复权漂移声明）：与 v0.1 语义一致（源自 trend-studio 基线），此处不重复；详见 [内容生产链路 §8 图示三路](../arch/05内容生产链路实现方案.md)、[教材呈现与交互课件 §7–9](../arch/06教材呈现与交互课件实现方案.md)（组件白名单、断言证明、确定性生成器）、[教材呈现与交互课件 §5 实盘层](../arch/06教材呈现与交互课件实现方案.md)（案例股与行情口径）。
- **三层校验**：schema → 语义（断言证明/术语/引用/媒体锚点）→ 教学质量（rubric 评分，grounded 含「行情数值可核」一票否决）。失败回灌重写 ≤ 3 次，超限显式进工作台**人工待办**，绝不部分落库。
- **门禁②（主编评审）**：工作台评审卡展示十维评分与逐段修改指令；verdict approve / reject；reject 进入回灌。
- **生产看板**：工作台主视图——每节一行九步状态 + 产出计数 + 最近评审结论 + 追加素材决策 + 人工待办入口；「当前步」口径与引擎一致；流程向导（每步目标/工具/常见坑）。

### B4 交接与发布（P0）

- **发布就绪度**（只读）：五道门禁（图示解析/课件断言/片段窗/标注与回放/终审签批）逐条判定 + 内容指纹 + 待办；**门禁判定一份实现**（就绪度与发布读同一批检查结果）。
- 结构化内容编辑（写恒为 draft）：节元数据 / 案例股清单 / 术语（归档可逆）三个编辑入口；**正文与课件的表现层修改走 B6 轻量编辑**，DSL 结构与事实段仍不在工作台手改（绕过行情与术语校验），结构性改动走生产回灌。
- 内容指纹覆盖一切会被发布的内容；改内容即已签批失效（`approval_stale`）。
- 签批与发布按钮**对教师隐藏**；发布由运营执行（迁移先行、重建索引、失败可回滚）。

### B5 异常与人工介入契约（P0）

| 异常 | 触发 | 处理契约 |
|---|---|---|
| 提纲与素材不匹配 | 综合校验发现某节证据不足（匹配度低于阈值） | 工作台标红该节并给出匹配度；教师裁决：**修订提纲**（编辑后重跑综合）或**补充素材**（上传后重跑）；其余节不受影响 |
| 课件证据不足 | 逐节生产中素材证据不足以支撑该节内容 | 子代理**挂起**该节（状态显式、进度保留），工作台提示补素材；补充素材入库后**自动恢复**，不重跑已完成步骤 |
| 校验 / 自评失败 | 三层校验或评审 Agent 不通过 | 回灌重写 ≤3 次；每次回灌带回具体失败原因；超限转人工待办 |
| 概念归一冲突 | 术语表归一时出现无法自动裁决的冲突 | 转人工待办，教师裁决后继续 |

共同纪律：异常状态在看板可见（不静默）；恢复动作幂等（重复触发不重复重置）；一切异常处理不产生部分落库。

### B6 教材轻量编辑（P0）

Agent 生成的教材仍需人工微调。工作台提供**所见即所得的直接编辑**：在渲染后的教材里选中元素即可修改，不必绕到对话里描述。所有写入仍为 `draft`。

**校验边界**：轻量编辑只允许「表现层 + 措辞」——文字、加粗/斜体/下划线、颜色、字号、对齐。**不得新增或删除事实段、不得移除 `[[unit:]]` 锚**。保存时自动跑轻校验（锚点仍在 + 行情数值未变则通过）；触及事实锚或数值的修改被拒绝并提示「结构性改动走生产回灌」。内容变更后内容指纹失效，已签批课程转 `approval_stale`（沿用 B4）。

- **文本编辑**：点击正文段落 / 标题即进入选中态，浮动工具条提供加粗、斜体、下划线、颜色、字号、对齐、清除格式；支持撤销 / 重做；右侧检查器显示该段来源 unit 与「改动将触发轻校验」提示。
- **图片编辑**：点击图片进入选中态，可**删除**或**替换**。替换面板三种来源——**素材库**（按本课程素材浏览）、**库内搜索**（关键字 / 类型）、**本地上传**（直传凭据，同 B2）。替换记录新旧素材 ID，可回退到原图。
- **K 线属性**：点击回放图打开属性检查器——**股票代码、周期（日线 / 周线）、起始时间、数据状态（已采集 / 部分 / 未采集）**。未采集时提供「去采集」动作并入队行情同步；代码或周期变更后重新读回行情并重校验；行情读回失败时该图降级为占位并显式提示，**不伪造数据**。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 并发与规格 | 生产 worker 池：逐节并行度上限可配；队列深度与 worker 健康可观测；单课生产不阻塞其他课 |
| 成本 | 生产用量（LLM/VLM）全部入云端用量账本（`source='producer'`）；按任务/模型/课程维度可查；组织预算 80% 预警、100% 硬停新增生产（在产任务不中断，显式提示 |
| 安全 | 教师仅持 Web 会话（sessionStorage，不落 Cookie）；无凭据托管面；云端文本按不可信数据处理（防提示注入）；密钥仅模型配置页加密维护 |
| 稳定性 | 长任务可中断恢复（队列 + 心跳）；校验失败不静默；回灌与待办显式 |
| 可观测 | 每个落库产物上报溯源（任务/模型/token/耗时/工艺版本）；不记密钥与产物正文 |

## 5. 验收标准

| 类别 | 用例 | 期望 |
|---|---|---|
| 零安装 | 新教师拿账号首次使用 | 浏览器打开工作台即可建课拖视频；全程无本地环境要求 |
| 直传 | 浏览器拖入 2GiB 内视频 | 进度可见；字节直达存储（不经业务进程内存中转）；中断可重试；无音轨拒绝并清理 |
| 增量 | 转写进行中 | 工作台可读已转写段落（`partial=true`）；理解提前起跑 |
| 门禁① | 骨架审批组件 | 目录外章节不被创建；概念重名 409；审批后逐节解锁 |
| 生产 | 九步跑错序 | 引擎报错并指出当前该做第几步 |
| 生产 | 单章全量 | 节教材+图示+课件全量通过三层校验入 draft；回灌 ≤3；绝不部分落库 |
| 评审 | reject | 工作台评审卡展示修改指令；回灌后复审 |
| 追加素材 | 选 A/B/C | 影响面先只读展示；决策入库；受影响节步骤重置而回灌预算保留 |
| 并发 | 两门课同时生产 | 互不阻塞；单课并行度受上限约束；worker 重启后续跑 |
| 交接 | 就绪度卡片 | 五道门禁与发布同源判定；内容变更后指纹失效转待重签 |
| 轻量编辑 | 选中正文段落改文字与样式 | 直改即可生效（无需走对话）；撤销/重做可用；写入仍为 draft |
| 轻量编辑 | 删除事实段 / 移除 `[[unit:]]` 锚 | 保存被拒并提示「结构性改动走生产回灌」；文件不变脏 |
| 图片编辑 | 选中图片删除或替换（库/搜索/上传） | 三种来源均可用；新旧素材 ID 留痕，可回退原图 |
| K 线属性 | 查看某图的代码/周期/起始时间/数据状态 | 属性可读可改；未采集显示占位并可「去采集」；改代码或周期后重读行情重校验，读回失败显式提示不伪造 |
| 分权 | 教师调签批/发布端点 | `403`；工作台不显示签批发布入口 |
| 成本 | 生产用量 | 每次模型调用入账本（任务/模型/课程）；预算触线预警与硬停生效 |

## 6. 平台约束

教师端约束仅为**浏览器**：现代 Chrome/Edge/Safari；大文件上传依赖直传凭据通道（浏览器原生 PUT）；会话令牌仅存 sessionStorage。dsh 平台基线不再约束教师端（仅学员端适用，见 [整体架构设计 §一 决策记录](../arch/01整体架构设计.md)）。
