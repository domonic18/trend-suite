# 教师端需求

> **一句话**：教师用浏览器把一段课程录像变成可发布的教材——九步生产由云端 Agent 承担，人只守住方案、评审和必要的微调。

- 读者：产品、云端开发

## 1. 谁在用，能做什么，不能做什么

**教师**（账号角色 `producer`）是课件制作人员：打开浏览器工作台就能做课，不装任何东西、不配任何密钥、不做运维。

| 边界 | 含义 |
|---|---|
| 只写草稿 | 教师的一切写入都是 `draft`；签批与发布是运营（operator/admin）的事 |
| 模型云端预置 | 生产用的模型（含 VLM 理解）由运营在模型配置页维护（加密存储、任务级主备绑定）；教师侧零密钥 |
| 结构不发明 | 课程目录以人工目录为先验骨架，Agent 只做校验与归一 |
| 零安装零配置 | 教师侧只有浏览器一个依赖；不上传密钥、不装插件、不连本地服务 |

**验收尺子**：新教师拿到账号，**打开浏览器即可制作第一节课**；全程只在三处被打断——方案审阅、评审驳回、追加素材处置。

## 2. 完整旅程

| 阶段 | 教师做什么 | 系统做什么 | 场景 |
|---|---|---|---|
| 准备 | 登录工作台 | 账号与模型已由管理员/运营备好 | T1–T3 |
| 素材与方案 | 建课、拖视频、触发方案、审阅方案 | 直传入库、增量转写、起草方案 | T4–T8 |
| 逐节生产 | 看板上盯进度，只在评审处介入 | 四角色 Agent 跑九步、三层校验、返工回灌、课堂编排 | T9–T13 |
| 交接与发布 | 就地微调教材、看就绪度、等运营签批 | 五项就绪度判定、内容指纹、运营发布 | T14–T18 |

## 4. 场景详述

### 4.1 准备

#### T1 首次登录进入工作台

**场景**：教师第一次拿到账号，要在最短时间内开始做课。

**前置**：管理员已建好 `producer` 账号；模型已由运营预置。

**操作**：用账号密码或一次性邀请码登录，打开生产工作台。

**系统行为**：
- 工作台是 `producer` 角色专属入口，学员账号不可见该入口
- 会话是 Web 会话，令牌仅存 `sessionStorage`，不落 Cookie
- 教师侧无需任何模型配置页面，也无需上传密钥

**预期结果**：
- 登录后直接进入工作台，看得到自己的课程列表与「新建课程」入口
- 全程零安装、零命令行、零配置项

#### T2 开通教师账号

**场景**：教研组新来一位老师，管理员要给他一个能登录的账号。

**前置**：管理员已登录运营控制台。

**操作**：在账号页新建 `producer` 账号，用密码（scrypt 哈希）或一次性邀请码（单次有效）交付。

**预期结果**：账号可登录；邀请码用过即失效；工作台只对 `producer` 开放。

#### T3 生产模型预置

**场景**：生产链路需要模型，运营要在教师开工前把模型配好。

**前置**：运营已登录运营控制台。

**操作**：在模型配置页维护 LLM / VLM / ASR 条目，做任务级主备绑定与连通性测试。

**预期结果**：
- 密钥 AES-GCM 加密存储，**明文不进浏览器、不进日志、不进响应**
- 连通性测试与正式调用走同一协议分支（避免「测试通、实际不通」）
- 主模型失败且可重试（429/5xx/超时）时自动切备；参数非法、媒体非法、内容审核拒绝**不切备**

### 4.2 素材与方案

#### T4 把视频拖进课程

**场景**：教师手上有一段 30 分钟的课程录像，要让它成为课程的原始素材。

**前置**：已在工作台新建或选中一门课程。

**操作**：把视频文件拖进课程页。

**系统行为**：
- 签发直传凭据（HMAC 绑定素材 + 字节数 + 摘要 + 有效期）
- 浏览器直接 PUT 字节到云端存储，**不经业务进程内存中转**
- 落库确认后入队转写；上传进度可见、可重试

**预期结果**：
- 单文件 ≤ 2GiB
- 视频必须同时含视频流与音频流；缺音轨直接拒绝并清理半成品
- 中断后可重试，不产生重复素材

#### T5 边传边看转写

**场景**：老师不想等整段转写结束才开工。

**前置**：视频已上传，转写进行中。

**系统行为**：每转完一块即落可读段落（`partial` 标记）；理解与生产提前起跑；关键帧轨道先于转写完成。

**预期结果**：转写进行中就能在页面上读到已转写段落，并标明是未完成内容。

#### T6 课程骨架与概念归一

**场景**：一门课要覆盖哪些章节、术语怎么统一，得先定下来。

**前置**：素材已入库；教师提交了课程目标与目录先验（可粘贴、可口述）。

**系统行为**：
- **目录先验**：以人工目录为骨架，目录外的内容不创建章节
- **概念归一**：术语进概念表，含别名与依赖边；重复名、自环直接拒绝

**预期结果**：产出一份可信的骨架与概念图谱；越界内容有明确拒绝理由而不是被静默吞掉。

#### T7 触发制作方案

**场景**：素材齐了，教师要让 Agent 起草课程方案。

**前置**：素材就绪度为 `ready`（或教师明确允许 `partial`）。

**操作**：选择素材集，提交课程目标与目录先验，点「生成制作方案」。

**系统行为**：
- 触发时预检所选素材就绪度
- **方案由教师显式触发**，Agent 不从上传行为推断课程边界

**预期结果**：产出骨架 + 概念图谱 + 术语表 + 分节计划草案，进入 T8 审阅。

#### T8 审阅方案：批准 / 微调 / 打回

**场景**：方案是整门课的骨架，教师要在开工前把住这一关。

**前置**：方案草案已生成，尚未解锁逐节生产。

**操作**：在工作台打开方案审阅卡，查看骨架、概念图谱、术语表、分节计划，选择一个动作。

**系统行为**：
- **批准**：方案锁定为基准版，解锁逐节生产
- **微调**：结构化编辑方案条目（章节增删合并 / 改名 / 概念别名 / 分节粒度），即时生效
- **打回**：给一句自然语言修改指令，综合 Agent 基于**已有 source units** 重起草——不重跑素材理解，秒级返回新草案
- **版本历史**：草案与人工修改留版本轨迹（v1 → v2 …）；确认后锁定，中途变更只能走 T9 的「重做骨架」

**预期结果**：只有批准才解锁生产；微调与打回都不丢已有理解成果。

#### T9 追加素材：课程做到一半又拖进一段视频

**场景**：课程做到第三章，发现缺一段素材，得决定怎么并进来。

**前置**：已有课程正在生产或已生产部分章节。

**操作**：拖入新素材，工作台先展示影响面（哪些节会被重评），再选择处置方式。

**系统行为**：
- 先只读展示影响面，教师确认后才执行
- 三种处置：**A 只补这节** / **B 重做课程骨架** / **C 只入库暂不生产**
- 决策持久化；受影响节的**生产步骤重置**，但**回灌预算保留**

**预期结果**：教师在看到影响范围后再决定；决策有记录，重复触发不重复重置。

### 4.3 逐节生产（约占全程 90% 的时间）

#### T10 逐节自动生产

**场景**：方案已批准，教师希望剩下的事尽量不用管。

**前置**：方案已批准，逐节生产已解锁。

**系统行为**——生产由云端 Agent 链承载，工具调用与确定性校验都落云端：

| 角色 | 职责 |
|---|---|
| 理解 Agent | 多模态逐 chunk 处理素材（转写分组 + 采样帧），产出 source units；随素材就绪自动运行 |
| 综合 Agent | 目录先验校验、概念归一、起草制作方案（含分节计划）；支持打回重起草（复用 units） |
| 逐节子代理 ×N | 每节一个并行子代理，按**九步固定顺序**生产：案例股 → 行情同步 → 行情读回 → 图示 → 回放课件 → 正文 → 其余课件 → 评审 → 溯源；**引擎强制顺序**（跑错序被挡并提示当前步）；断点续跑（云 DB 即 checkpoint，worker 崩溃恢复不依赖本地状态）；并行度有上限 |
| 评审 Agent | rubric 十维自评（grounded 含「行情数值可核」一票否决），生成逐段修改指令 |

同一批产物还要满足：
- **教材正文**：Markdown 扩展 DSL + `[[unit:]]` / `[[stock:]]` 锚；事实段落必须可回溯 source unit
- **图示三路**：diagram（生成）/ keyframe（讲师关键帧）/ generated（文生图，仅装饰）——有配额，且**不得承载教学信息**
- **课件**：11 类组件白名单 + 断言词表 + 确定性生成器（详见 [教材呈现与交互课件 §7–9](../arch/06教材呈现与交互课件实现方案.md)）
- **案例股与行情口径**：腾讯前复权、周期原生日 K / 周 K、均线位白名单、复权漂移声明（详见 [教材呈现与交互课件 §5](../arch/06教材呈现与交互课件实现方案.md)）

**三层校验**：schema → 语义（断言证明 / 术语 / 引用 / 媒体锚点）→ 教学质量（rubric 评分，grounded 含「行情数值可核」一票否决）。失败即回灌重写，**≤ 3 次**；超限进 T14 人工待办，**绝不部分落库**。

**预期结果**：一节内容要么完整通过三层校验进入草稿，要么显式挂起或进待办，不存在「半成品入库」。

#### T11 在看板上盯进度

**场景**：教师想随时知道整门课到了哪一步。

**系统行为**：生产看板是工作台主视图——每节一行九步状态 + 产出计数 + 最近评审结论 + 追加素材决策 + 人工待办入口；「当前步」口径与引擎一致；每步附目标、用的工具、常见坑。

**预期结果**：看板显示的当前步与引擎实际所在步骤一致，不出现两套口径。

#### T12 评审与返工

**场景**：一节做完了，但质量不够，要打回重做。

**前置**：某节通过校验，进入主编评审。

**操作**：在工作台评审卡看十维评分与逐段修改指令，给出 approve / reject。

**系统行为**：reject → 回灌重写（带修改指令，≤ 3 次）；每次回灌带回具体失败原因。

**预期结果**：approve 的节进入草稿；reject 的节带着明确的修改指令重跑，不是从零重做。

#### T13 把教材编排成课堂

**场景**：教材写好了，但学员要的是「有人讲」的课。教师要把这一节变成可播放的课堂：讲解稿、白板脚本、引导点、随堂测验。

**前置**：该节的教材与互动课件已通过三层校验。

**操作**：在工作台进入「课堂编排」，为本节生成或调整课堂内容。

**系统行为**：
- **场景骨架**：一节课编排为若干场景序列，四类——讲解页 / 随堂测验 / 交互课件 / 项目制练习
- **讲解稿**：逐段讲解文本（含元素引用与讲解顺序），教学要点必须来自教材正文与已通过的 source unit
- **白板脚本**：逐笔绘制动作（文字 / 图形 / 图表 / 公式 / 表格 / 代码），与讲解稿逐句对齐
- **引导点**：标注高亮、激光笔、组件引导的落点，课堂运行时按脚本触发
- **随堂测验**：单选 / 多选 / 简答题与判分反馈（答案唯一、解析可回溯 source unit）
- **人设**：AI 同学与辩论角色的人设（身份、声音、性格），角色数与音色可配
- **一致性**：课堂内容与教材同源——正文改动即课堂失效（内容指纹覆盖课堂），杜绝教材与课堂讲的不一致

**预期结果**：
- 课堂内容与教材一起进草稿、一起进发布就绪度判定
- 课堂不引入教材里没有的结论（grounded 纪律对课堂同样生效）
- 讲解音轨不由云端预生成——课堂只存讲解文本与脚本，音轨在客户端本地合成

> **对标**：场景类型与动作词表参考 [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)（MIT）的课堂契约；差异是本项目的课堂**发布前编排好**、音轨本地合成，不即时生成。

#### T14 人工待办

**场景**：有些问题 Agent 判不了，必须人来裁决。

**系统行为**：回灌超限（≤3 次未收敛）、概念归一冲突等显式待办进入工作台待办区。

**预期结果**：待办可见、可处理，**绝不静默丢弃**。

### 4.4 交接、发布与轻量编辑

#### T15 看发布就绪度

**场景**：教材做完了，教师想知道能不能发。

**系统行为**：就绪度为只读，五道门禁（图示解析 / 课件断言 / 片段窗 / 标注与回放 / 终审签批）逐条判定，附内容指纹与待办数。

**预期结果**：**门禁判定一份实现**——就绪度与发布读同一批检查结果，两边结论不会打架。

#### T16 结构化编辑

**场景**：某些元数据要精确改，不能靠 Agent 重写。

**系统行为**：三个编辑入口——节元数据 / 案例股清单 / 术语（归档可逆）；写恒为 draft。

**预期结果**：改动可逆、可追溯；正文与课件的**表现层**修改走 T17，DSL 结构与事实段不在这里手改。

#### T17 教材轻量编辑

**场景**：Agent 写出来的教材，教师想直接改几个字、换张图、调一下 K 线，不必绕到对话里描述一遍。

**前置**：该节教材已生成并渲染。

**操作**：在渲染后的教材里选中元素直接改。

**系统行为**：
- **文本**：点击正文段落 / 标题进入选中态，浮动工具条提供加粗、斜体、下划线、颜色、字号、对齐、清除格式；支持撤销 / 重做；检查器显示该段来源 unit 与「改动将触发轻校验」提示
- **图片**：点击图片进入选中态，可删除或替换。替换有三种来源——**素材库**（浏览本课程素材）/ **库内搜索**（关键字、类型）/ **本地上传**（直传凭据，同 T4）；替换留痕新旧素材 ID，可回退原图
- **K 线属性**：点击回放图打开属性检查器——股票代码、周期（日线 / 周线）、起始时间、数据状态（已采集 / 部分 / 未采集）。未采集时提供「去采集」并入队行情同步；改代码或周期后重新读回行情并重校验；读回失败时该图降级为占位并显式提示，**不伪造数据**

**校验边界**：轻量编辑只允许「表现层 + 措辞」。**不得新增或删除事实段、不得移除 `[[unit:]]` 锚**。保存时自动跑轻校验（锚点仍在 + 行情数值未变则通过）；触及事实锚或数值的修改被拒绝并提示「结构性改动走生产回灌」。

**预期结果**：改完即时生效、仍是草稿；内容变更后内容指纹失效，已签批课程转 `approval_stale`（见 T15）。

#### T18 签批与发布

**场景**：课做好了，要发出去。

**系统行为**：签批与发布按钮**对教师隐藏**；发布由运营执行（迁移先行、重建索引、失败可回滚）。

**预期结果**：教师调到签批 / 发布端点返回 `403`；工作台不出现签批与发布入口。

### 4.5 异常与人工介入契约

| 异常 | 怎么触发 | 系统怎么处置 | 教师做什么 | 预期结果 |
|---|---|---|---|---|
| 提纲与素材不匹配 | 综合校验发现某节证据不足（匹配度低于阈值） | 该节标红并给出匹配度 | 二选一：**修订提纲**（编辑后重跑综合）或**补充素材**（上传后重跑） | 其余节不受影响 |
| 课件证据不足 | 逐节生产中素材证据不足以支撑该节内容 | 子代理**挂起**该节（状态显式、进度保留） | 补素材 | 补充素材入库后**自动恢复**，不重跑已完成步骤 |
| 校验 / 自评失败 | 三层校验或评审 Agent 不通过 | 回灌重写 ≤3 次，每次带回具体失败原因 | 超限后按待办处理 | 不产生部分落库 |
| 概念归一冲突 | 术语归一时出现无法自动裁决的冲突 | 转人工待办 | 裁决后继续 | 不静默跳过 |

**共同纪律**：异常状态在看板可见；恢复动作幂等（重复触发不重复重置）；一切异常处理都不产生部分落库。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 并发与规格 | 生产 worker 池：逐节并行度上限可配；队列深度与 worker 健康可观测；单课生产不阻塞其他课 |
| 成本 | 生产用量（LLM/VLM）全部入云端用量账本（`source='producer'`）；按任务/模型/课程维度可查；组织预算 80% 预警、100% 硬停新增生产（在产任务不中断，显式提示） |
| 安全 | 教师仅持 Web 会话（sessionStorage，不落 Cookie）；无凭据托管面；云端文本按不可信数据处理（防提示注入）；密钥仅模型配置页加密维护 |
| 稳定性 | 长任务可中断恢复（队列 + 心跳）；校验失败不静默；回灌与待办显式 |
| 可观测 | 每个落库产物上报溯源（任务/模型/token/耗时/工艺版本）；不记密钥与产物正文 |

| T8 | 方案审批组件 | 批准后逐节解锁；微调即时生效；打回秒级返回新草案且不重跑素材理解 |
| T10 | 九步跑错序 | 引擎报错并指出当前该做第几步 |
| T10 | 单章全量 | 节教材+图示+课件全量通过三层校验入 draft；回灌 ≤3；绝不部分落库 |

| T13 | 课堂编排 | 讲解稿 / 白板脚本 / 引导点 / 随堂测验齐备且与教材同源；正文改动后课堂同步失效 |
| T9 | 追加素材选 A/B/C | 影响面先只读展示；决策入库；受影响节步骤重置而回灌预算保留 |

| T17 | 选中正文段落改文字与样式 | 直改即可生效（无需走对话）；撤销/重做可用；写入仍为 draft |
| T17 | 删除事实段 / 移除 `[[unit:]]` 锚 | 保存被拒并提示「结构性改动走生产回灌」；文件不变脏 |
| T17 | 选中图片删除或替换（库/搜索/上传） | 三种来源均可用；新旧素材 ID 留痕，可回退原图 |
| T17 | 查看某图的代码/周期/起始时间/数据状态 | 属性可读可改；未采集显示占位并可「去采集」；改代码或周期后重读行情重校验，读回失败显式提示不伪造 |
| T18 | 教师调签批/发布端点 | `403`；工作台不显示签批发布入口 |
| 成本 | 生产用量 | 每次模型调用入账本（任务/模型/课程）；预算触线预警与硬停生效 |

## 7. 边界与不做的事

- 教师端只有浏览器一个依赖：不提供本地安装、不提供密钥配置、不提供运维入口。
- 教师不签批、不发布、不做索引重建。
- 事实段与 DSL 结构不在工作台手改——改这些走生产回灌（见 T17 的校验边界）。
- 图示不承载教学信息；教学信息只由正文、课件与断言承担。
