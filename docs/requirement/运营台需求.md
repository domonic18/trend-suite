# 运营台需求

> **一句话**：运营在浏览器控制台维护系统级配置——账号、生产模型、行情数据源；配置即生效，密钥永不回显。

- 读者：产品、云端开发

## 1. 谁在用，能做什么

**运营**（角色 `operator`）只读系统配置；**管理员**（角色 `admin`）可写。运营台当前两页：

| 页面 | 管什么 | 谁可写 |
|---|---|---|
| 模型配置 `/ops/models` | 模型条目（内容生成 / 视觉理解 / 语音转写 / 向量嵌入 / 图像生成）、任务槽位主备绑定、ASR 渠道 | admin（operator 只读） |
| 行情源 `/ops/market` | K 线数据来源条目：默认源、启停、连通性测试 | admin（operator 只读） |

**验收尺子**：运营不做任何命令行操作；换模型密钥或换行情源后，下一轮生产任务即刻走新配置，无需重启服务。

## 2. 模型配置（M1–M4）

| 编号 | 场景 | 系统行为 |
|---|---|---|
| M1 | 维护模型条目 | 每条可选多个用途；选择预置厂商自动填充该协议端点（可改）；密钥 AES-GCM 加密存储，**明文不进浏览器、不进日志、不进响应**，列表只回掩码 |
| M2 | 连通性测试 | 与正式调用走同一协议分支（避免「测试通、实际不通」）；点击后行内显示「测试中…」，结果（延迟 / 失败原因）随条目落库内联展示 |
| M3 | 任务主备绑定 | 每任务槽位绑定主模型（必填）与备用（可选）；主模型可重试失败（429/5xx/超时）时自动切备，参数非法 / 媒体非法 / 审核拒绝不切备 |
| M4 | 权限 | 写操作仅 admin；operator 与 producer 调写端点均 `403` |

## 3. 行情源配置（Q1–Q4）

| 编号 | 场景 | 系统行为 |
|---|---|---|
| Q1 | 维护行情源条目 | 名称 + Base URL（fqkline 协议口径不变）+ 备注 + 启停；预置默认源一条（腾讯前复权）；**至多一个默认源**，设新默认自动清旧 |
| Q2 | 运行时取源 | 生产同步与学员端读回取**默认启用源**（缓存 ≤60 秒，改完即生效不重启）；显式设置环境变量 `MARKET_QUOTES_BASE_URL` 时该变量优先（本地开发 / 测试口径）；查库失败回退环境变量默认值，**绝不抛错**（worker 不因配置缺失挂死） |
| Q3 | 测试连接 | 与正式调用走同一客户端分支，真实拉一只样本 A 股的日线 K 线；结果（连通 / 延迟 / 样本根数 / 失败原因）随条目落库内联展示 |
| Q4 | 删除约束 | 默认源不可删——先设其他源为默认再删；全部源删除或停用后运行时回退环境变量默认地址，生产不断流 |

## 4. 验收清单

| 用例 | 期望 |
|---|---|
| admin 新增行情源并设为默认 | 旧默认自动让位；列表只有一个「默认」徽章 |
| admin 对新源点测试连接 | 行内显示延迟与样本根数；失败显示原因与时间 |
| 改默认源后触发一节「同步行情」 | 拉数请求发往新源（服务端日志可核） |
| operator 调行情源写端点 | `403`；页面上写按钮不出现 |
| 删除默认源 | 被拒并说明先设其他源为默认 |
| 数据库不可达时 worker 同步行情 | 回退环境变量默认地址，不抛错、任务不挂 |

## 5. 边界与不做的事

- 运营台不配置模型用途之外的生产参数；不做行情多供应商协议适配（协议仍是 fqkline，仅来源地址可配）。
- 教师端不出现行情源入口；行情源与模型配置一样是系统级配置。
