老师说的“阻尼运动”是什么意思？和普通回调有什么区别？
势
阻尼运动是趋势运行中动能逐步衰竭的比喻：价格仍沿原方向创新高，但每一段的幅度与斜率递减，如同振幅衰减的弹簧。

与普通回调的区别在级别与证据：回调是次级别的反向运动；阻尼是本级别动能的衰减，需要「幅度递减 + 均线粘合 + 量能萎缩」三者共同验证。
