# 原型图（prototype/）

生产级静态原型，可直接打开（无需构建）。命名：`portal-*`（公开网站——主页 / 登录 / 注册 / 设备授权 / 个人中心）/ `student-*`（**dsh 客户端内页面**——首启 / 我的课程 / 对话 / 课程）/ `teacher-*`（教师生产工作台，浏览器）/ `ops-*`（运营控制台）。公开内容（能力介绍、下载安装、定价、FAQ、法务）全部收敛在主页 `portal.html` 内。

**原型不是契约材料**：评审采纳的结论回写 `requirement/` 与 `arch/`；原型与需求冲突时以需求为准。

入口：[index.html](index.html)（原型索引，含全部页面与两条运行图的跳转、页面 ↔ 流程节点映射）。

## 组织方式

- **共享样式底座 + 页面级少量内联**（不逐页复制内联——复制发散会导致页面拼接错乱）：
  - `assets/tokens.css`：全局设计 token（三族色板 / 字体 / 圆角 / 行情红涨绿跌）
  - `assets/family-portal.css`：门户族底座（玻璃吸顶导航 / home-hero / 能力图文 / page-hero + auth-card / account 面板 / 浅色页脚）
  - `assets/family-teacher.css`：教师工作台底座（旅程步进器 / 告警条 / 节卡片九步格 / 任务计划卡 / rubric / 工具卡，浅色；shell 复用 family-ops）
  - `assets/family-agent.css`：教师端 Agent 协作层（三栏 `has-agent` / 阶段条 / 单一主行动 / Agent rail / 消息与计划 / 工具卡 / 子代理树 / HITL 决策卡 / 产物树 / 审核分栏与就绪度）
  - `assets/family-ops.css`：运营控制台底座（后台管理布局：侧栏 + 顶栏面包屑 + 面卡表格，浅色门户色板）
  - `assets/family-dsh.css`：dsh 客户端族底座（三栏 + 右栏 + 底部终端行 + 引用芯片 + 额度 pill + 明暗两套主题变量）
  - `assets/dsh-right.js`：dsh 客户端族交互集（右栏页签 / 中央视图页签 / 侧栏折叠 / 右栏开合 / 底部栏收起 / 模式循环 / 主题切换 / 上下文开关）
- **页面间导航全量接线**：导航一律 `<a href>`（含锚点），页内动作用 `<button>`。
- **运行图跳转**：`../flow/*.html` 内节点注入了「原型」芯片与右下角图例（`ts-proto-*`）；流程图再生成后需重放注入。

## 设计语言

### 门户族（官网 / 落地 / 注册 / 登录 / 设备授权 / 个人中心）

蓝 `#2563eb` 主色 + 绿 `#0f9d76` 点缀；毛玻璃吸顶导航 + 活性胶囊；径向渐变 hero（蓝绿柔光）+ kicker 胶囊 + 四格数据卡；三/四列能力卡（卡片投影 `0 18px 48px`）；双列大数字步骤路径；深蓝渐变 CTA 带（`#11203d → #1d3b74`）；页宽 `min(1160px, 100vw−48px)`。

### 工作台族（教师 / 运营）

浅色后台（与门户同族）：复用 ops shell（侧栏 + 顶栏面包屑 + 面卡）与门户色板（蓝 `#2563eb` / 绿 `#0f9d76`）。教师页统一**三栏 Agent 协作布局**：导航 / 主区 / 常驻 Agent rail；rail 为**单流对话**（执行过程内联在消息里，不另开「执行」页签），产物按单元归入中间栏页签；确认与待办以对话内决策卡呈现。工作台收敛为**两页模型**——原始数据（上传 / 解析 / 逐字稿 / 关键帧）与教材（结构树 + 渲染后的 HTML 教材 + Agent 生成侧栏），侧栏仅「所有课程 / 原始数据 / 教材 / 用量与成本」。

### dsh 客户端族（首启 / 我的课程 / 对话 / 课程页）

**DSH 框架 + trend-coach 插件**——在 DeepSeek Harness 框架上做插件开发，框架组件保留、插件注入分层：

- **框架部分**：侧栏品牌行（DeepSeek Harness · 折叠钮可用）、「新会话」大按钮（`#43454a`·r12·kbd 芯片 ⌘N）、框架面板导航（插件 / 自动化任务 / 更多）、工作区节头（工作区名 + 搜索）、会话树（时间分组）、底部用户行；中央 = 40px 头部（面包屑 + chips + 终端/右栏开合角标）→ 框架页签 **对话 / 轨迹 / 用量**（页内切换）→ 滚动体 → composer（框架模式 chips **自动** / **Default** + 插件 chips）；右栏统一三页签 **文件 / 终端 / 播放器**（可收起，插件内容并入对应面板）；底部**终端行**（标题 + NodeJS 诊断 + 插件运行日志 + 左下角状态簇「命令模式 / 主题切换」，可收起）。
- **插件注入部分**：品牌玉绿作为插件主操作色（明亮 `#17936f` / 暗黑 `#3DBE9B`）——插件注入行、发送、引用、播放进度、新会话按钮。
- **布局**：全视口 `.dsh`（纵向：`.dsh-row` 三栏 + `.dsh-bottom`），侧栏 264px、8px 拖拽分隔条。
- **主题**：默认明亮（`body.dsh-light`，侧栏 `#f7f7f8` / 中央 `#fff`），可临时切暗黑（侧栏 `#1b1b1c` / 中央 `#151517`）；四页默认明亮、主题按钮统一「明亮」。
- **会话视图**：845px 窄列、用户右侧气泡（`#2c2c2e`·r20·最宽 82%）、助手通栏 markdown、「加载更早」胶囊（`#353638`·r8）；文字三级 `#f9fafb/#cfd3d6/#adb2b8`；圆角 8/12/16/20。

### 通用

行情图表红涨绿跌（`#e05d68/#31a984`，深色底）；全程零 emoji，16px 线性 SVG 图标。
